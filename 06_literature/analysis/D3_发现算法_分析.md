# D3 攻击发现算法：36 篇分析

> 分析日期 2026-08-06；底料为 `papers/D3_发现算法/*.pdf` 首页摘要全文。

## 1. 一句话总判断

这 36 篇算法的共同转向是：**从“单次优化出完美攻击”转向“预算约束下的多样性搜索”**——质量-多样性（Rainbow）、好奇心（CRT）、多目标演化（EvoJail/BlackDAN）、模块组合（MAD-MAX）、树搜索+种子选择（AgentVigil/MUSE）、过程奖励（TROJail）。这正好对上 JED 的评分结构（severity + 2×unique_cell）和回放预算约束。

## 2. 聚类

### 簇 C1：演化 / 遗传 / 多目标搜索（7 篇）
EvoJail（2605.02921）、DARWIN（2607.19829）、GAS-Leak-LLM（2606.15788）、BlackDAN（2410.09804）、HAMSA（2508.16484）、ACE-Safety/GS-MCTS（2511.19218）、MAD-MAX（2503.06253）。

关键机制：
- EvoJail：field-aware instruction fusion 构造多样起点 + diversity-aware fitness（有效性×多样性）+ 多级 LLM 变异算子 → **与我们的 N4/N5 直接对应：适应度=得分×新签名族**。
- MAD-MAX：攻击策略自动聚类→按恶意目标选簇→跨簇组合；97%（GPT-4o/Gemini）vs TAP 66%，平均 10.9 次查询 vs 23.3；相似性过滤省预算 → **组合策略 + 相似性去重 = 回放预算下的最优选择结构**。
- DARWIN：策略来源=外部文献+自反思+遗传变异，按护栏反馈筛选组合；几乎 100% ASR → 护栏更新后旧策略失效，模板库要持续演化。
- BlackDAN：NSGA-II 多目标（ASR、隐蔽性、语义相关性）帕累托前沿 → 本地 mock 上可用帕累托选择代替单分数排序。
- GAS-Leak/HAMSA：词级遗传后缀、温度控制变异 → 变异算子库来源。

### 簇 C2：强化学习红队（5 篇）
Automatic LLM Red Teaming（2508.04451）、Jailbreak-R1（2506.00782）、LLMStinger（2411.08862）、TROJail（2512.07761）、RedTopic（2507.00026）。

关键机制：
- TROJail：轨迹级 RL + 两个过程奖励：① 惩罚过早有害（触发拒绝）的中间 prompt；② 鼓励把回复语义引向目标 → **多轮链中间步的设计原则：中间步绝不能暴露恶意，必须逐步拉近语义**。这是 M1 重做的直接算法依据。
- Automatic LLM Red Teaming：MDP + 分层 RL + token 级危害奖励，学多轮策略 → 证明多轮攻击需要“轨迹级”优化而非单轮。
- Jailbreak-R1/LLMStinger：冷启动 SFT + 多样性/一致性奖励 + 渐进危害奖励 → 离线模板进化的三阶段结构。
- RedTopic：多目标 RL 奖励兼顾主题多样性 → 主题网格覆盖。

### 簇 C3：树搜索 / 束搜索 / 贝叶斯 / 测试时扩展（6 篇）
AgentVigil（2505.05849）、MUSE-A（2509.14651）、BEAST（2402.15570）、GASP（2411.14133）、AutoDAN-Reasoning（2510.05379）、AmpleGCG（2404.07921）。

关键机制：
- AgentVigil：**通用黑盒 IPI fuzz：高质量种子语料 + MCTS 种子选择 + 迭代精化**；AgentDojo 71%、VWA-adv 70%（近翻倍于 baseline），强迁移、抗防御 → 与我们的比赛最接近的可实现算法，P0 必读全文。
- MUSE-A：frame semantics + 启发式树搜索，多轮语义轨迹 → 多轮候选树的构建。
- AutoDAN-Reasoning：Best-of-N（N 候选选最优）+ Beam Search（策略组合）→ 预算固定时，Beam Search 组合策略提升最高 15.6pp；对 GPT-o4-mini 相对提升 ~60%。
- BEAST：束搜索 1 分钟越狱，可解释参数平衡速度/成功率/可读性 → 本地 mock 上的快速候选生成。
- GASP：隐空间贝叶斯优化生成人类可读后缀 → 黑盒低预算优化。
- AmpleGCG：GCG 中间步的成功后缀做成生成模型，4 秒 200 后缀 → “中间产物不丢”的思想：我们的每次提交轨迹里的成功 finding 都该回注模板库。

### 簇 C4：质量-多样性 / 好奇心 / 开放式 / 种子生成（6 篇）
Rainbow Teaming（2402.16822）、CRT（2402.19464）、WildTeaming（2406.18510）、RedAgent（2407.16667）、AutoRed（2510.08329）、KDA（2502.05223）。

关键机制：
- Rainbow Teaming：把攻击生成定义为 QD 问题，开放式搜索，ASR>90% 且高迁移 → **unique cell 的直接算法**：行为特征空间（如工具签名）上做 MAP-Elites 式归档。
- CRT：好奇心（novelty）驱动探索提升覆盖率且保持有效性 → F004 的理论实现。
- WildTeaming：野外 5.7K 战术簇 + 组合 → 战术分类学来源（不用其具体 prompt，只借结构）。
- RedAgent：把攻击抽象成“越狱策略”概念，多智能体+记忆缓冲自反思 → 上下文自适应策略选择。
- AutoRed：免种子 persona 引导生成 + 反射循环 + 无查询 verifier → 本地 mock 预筛可借鉴“verifier 不查询目标”的思路。
- KDA：把多个 SOTA 攻击者蒸馏成一个模型 → 无 GPU 不投，但“多样性+集成是效果关键”的结论支持 N5。

### 簇 C5：智能体专用红队（4 篇）
SIRAJ（2510.26037）、AgentVigil（2505.05849，亦属 C3）、Profit is the Red Team（2603.20925）、Go-Explore for AI Red Team（2601.00042）、AutoRedTeamer（2503.15754）。

关键机制：
- Go-Explore 红队（我们最关键的实证）：28 次实验——随机种子方差主导（8× 跨度，单种子不可信）；**reward shaping 有害**（94% 探索崩溃或 18 个假阳性零验证攻击）；**简单状态签名优于复杂**；集成=攻击类型多样性，单 agent=类型内覆盖 → 直接指导本地判官（多盐）与枪口分配（多签名族并行）。
- SIRAJ：seed 生成按“风险结果 × 工具轨迹 × 风险源”三维网格，覆盖 2-2.5×；蒸馏红队模型 → 种子库结构直接可用。
- Profit：标量反馈学对手策略（探测/锚定/欺骗承诺）→ 本地 mock 分数可当标量反馈，但只能预筛。
- AutoRedTeamer：红队 agent + 策略提案 agent 双智能体，终身整合新攻击 → 我们的模板库维护流程。

### 簇 C6：综述 / 实证 / 通用优化（5 篇）
Jailbreak Survey（2407.04295）、JailbreakZoo（2407.01599）、Red Teaming Overview（2503.01742）、Automation Advantage/Crucible（2504.19855）、TextGrad（2406.07496）。

关键事实：
- Crucible：214,271 次攻击实证，自动化 ASR 69.5% vs 人工 47.6%；自动化擅长系统探索 → 我们的全自动搜索方向正确。
- TextGrad：文本“梯度”优化复合系统 → 通用框架，可作为本地模板变异引擎的启发。
- 综述类当索引与分类学使用。

## 4. 优先级

- **P0 精读全文**：AgentVigil（可实现算法+代码）、Rainbow Teaming（QD 实现）、Go-Explore Red Team（实验结论）、MAD-MAX（组合+去重）、TROJail（过程奖励）、SIRAJ（seed 网格）。
- **P1 精读方法部分**：AutoDAN-Reasoning、EvoJail、DARWIN、BlackDAN、CRT、WildTeaming、RedAgent。
- **P2 按需翻阅**：其余 23 篇（综述当索引，训练型方法记录但不在本地落地）。

## 5. 结论

D3 的净信号：**在无 GPU、本地 mock≠真模型的约束下，最该抄的三样东西是：① AgentVigil 的 MCTS 种子选择流水线；② Rainbow Teaming 的质量-多样性归档（直接补 unique cell）；③ Go-Explore 红队的实验纪律（多盐、简单签名、不做 reward shaping）**。这三样不需要训练、不需要真模型在线反馈，可以在本地 deterministic mock 上落地，再用公榜单点验证。
