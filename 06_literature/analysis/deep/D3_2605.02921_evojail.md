# D3-2605.02921 EvoJail: Evolutionary Diverse Jailbreak Prompt Generation（EvoJail）
> 精读：2026-08-19 ｜ 全文 28 页 ｜ 底料 extracted_full/D3_2605.02921.txt
> 一句话：把越狱提示生成形式化为"安全分+多样性分"的加权和黑盒多目标进化搜索，用字段级指令融合初始化 + 精英-混合选择 + 四粒度 LLM 变异，在 5 个安全对齐模型上拿到 93–99% ASR，多样性 0.488 超最强基线 TAP(0.462) 5.6%，单次成功仅约 75 查询/34k tokens。

## 1. 问题设定（搜索目标/适应度定义）
黑盒设定（只有输入输出），目标不是单个越狱提示而是集合 A={p1..pK}⊆P_jail：跨模型版本持续有效 + 结构/语义/领域多样。核心形式化：**F(p) = w1·S(p) + w2·D(p|P)**，w1+w2=1。
- S(p)：安全风险分。GPT-4o-mini 按 Just-Eval 打 1–5 分（越低越有害），反转归一 S=(5−x)/4。
- D(p)：相对当前种群的新颖度，D=1−(1/(N−1))Σsim(p,pj)，sim 用 **TF-IDF 向量余弦**（注意：最终评估才换 sentence-embedding，搜索内环用便宜的 TF-IDF）。
- 权重扫描结论：w1∈[0.4,0.6] 区间三指标同时稳定，取 0.5/0.5 为默认；纯安全(w2=0)压多样性，纯多样性(w1=0)ASR 不稳。

## 2. 方法细节（伪代码级）
**初始化（指令融合）**：辅助 LLM 先生成 20 领域×10 任务=200 条良性载体指令（JSON 数组输出）；M_fuse 把恶意目标 h 融进载体 t：融合提示词极简——"把两条指令合并为一条，保持指令 2 的核心意图"。本质是"良性任务包裹恶意 payload"的混淆初始化，避免随机初始化的语法破碎。

**每代循环（N=10，G=10，α=0.1）**：
1. 逐个评 S、D，算 F；若 S 判定越狱成功且 F>τ → 提前返回。
2. 精英保留：Top αN=1 个直接进下一代，不做交叉变异。
3. 混合选择剩余 9 个：**50% 轮盘赌（按 F 比例）+ 50% 锦标赛（k=3）**——轮盘保底探索（低适应度仍有非零概率），锦标赛抗极端值。
4. 变异：交叉 p=0.5（两父代"交织"合成新指令，保留恶意意图）；变异 p=0.1，随机四选一：
   - 词级（同义词替换）；句级（主被动/陈述改疑问）；语义级（隐喻/术语/委婉语遮蔽敏感词）；**结构级（拆成多个子问题、编码/leetspeak 替换关键词）**——结构级实质就是多步分解。
   所有变异提示词统一要求"保留 {harm_instruction} 核心含义"。
5. P ← 精英∪新代。

## 3. 实验与关键数据
- 主表（JBB-Behaviors 100 行为）：ASR = Llama-3.3-70B 99 / Qwen2.5-14B 98 / DeepSeek-R1-14B 98 / GPT-3.5-Turbo 98 / **GPT-4o 93**（第二名 FlipAttack 68，JAIL-CON-CVT 在 GPT-4o 上 0）。NRR 普遍 90–100。
- 适应性：1405 条真实越狱模板随版本迭代衰减（GPT-3.5→4o 只剩 16 条有效）；EvoJail 重跑进化即恢复（GPT-4o 93）。
- 多样性：0.488 vs TAP 0.462、PAIR 0.459、PAPILLON 0.392、JAIL-CON-CVT 0.002（模板法几乎无多样性）。20 领域融合 ASR 均值 91.25%（游戏 96 最高）。
- 效率：QPS≈75 查询、TPS≈3.4 万 token/成功（PAPILLON 140/3.8万，AutoDAN 270/11万，PAIR 200/4.4万，SAA 8392 查询）。总时长 GPT-4o 上 8h48m。
- 消融：去交叉 −8 ASR，去变异 −12，**两者都去 −38（掉到 55%，但 NRR 仍 96 → 融合初始化本身已解决"不被拒"，交叉变异解决"拿到有害内容"）**。
- 参数：种群 4→16 ASR 79→94；多样性在种群 8→10 时 +5.6% 后趋平；迭代数超过 10 后多样性**下降**（早熟收敛信号）。

## 4. 失效条件与开销
- 迭代>10 多样性开始下滑——固定种群下约 10 代耗尽新颖度，需重初始化或多族群。
- 强意图检测模型（GPT-4o）上简单任务并行类方法崩塌（JAIL-CON 0–3%），EvoJail 靠每代真实评估+定制化仍撑住。
- 依赖判官质量：换辅助 LLM（Qwen3-plus）NRR −3%，整体 <3% 波动，对辅助模型不敏感。
- 开销：每受害者模型约 8.8 小时（辅助 LLM 通信延迟占大头）；跨模型迁移率低（源 Llama-3.3 平均迁移 ASR 仅 36.75%，源 GPT-4o 62.75%——弱模型上搜出的提示迁移差）。

## 5. JED 映射
1. **适应度直接抄结构**：JED 的 raw = Σseverity + 2×unique_cell 本身就是"效能+多样性"加权和。把候选账本排序函数改成 F = w1·(severity/16) + w2·(新增格子数/期望上限)，w 取 [0.4,0.6]——EvoJail 的权重扫描直接给了这个区间，省一次扫参。
2. **D(p) 用"格子新颖度"替换 TF-IDF**：JED 的 cell=工具签名覆盖，比语义相似更贴近计分。D(p)=该候选覆盖但账本未覆盖的 cell 数（归一化），账本本身就是种群。
3. **精英-混合选择用于变体预算分配**：每轮保留 top 10% 候选不变异（防丢失已验证模式），其余预算 50% 按 F 比例轮盘、50% 三选一锦标赛挑父本做变异——比均匀变异分配更聚焦。
4. **结构级变异=多步拆解算子**：四粒度变异里"拆成多个无害子问题+关键词编码"与 JED 多步攻击路径天然同构：对已成功路径做"步骤重排/子目标拆分/参数同义替换"三种粒度变异，交叉 0.5、变异 0.1 的配比可作默认。
5. **载体融合初始化**：与其随机起手，不如先离线生成"良性任务×攻击谓词"融合种子（如把 EXFILTRATION 谓词包进报表汇总/邮件草拟类任务），对应其 20 领域×10 任务的载体库做法。
6. **早停条件**：S 成功且 F>τ 即停——JED 沙盒探针同理，命中新谓词+新格子即冻结该候选转下一种子，别把预算烧在同格子上。
7. **预算参照**：75 查询/成功、10 代×10 种群的配置在 18000s/模型预算内可支撑约百次完整进化回合；"10 代后多样性衰减"提示 JED 搜索应"代数小、多轮重初始化"而非单轮长跑。

## 6. 优先级判定：**P1（本周可试）**
理由：方法本身是纯 prompt 空间的进化（非工具型 agent 场景），不能整搬；但其**适应度结构（效能+新颖度加权和及 0.4–0.6 权重鲁棒区）、精英-混合选择、四粒度变异算子族、载体融合初始化**四件套全部可直接改造进现有 mock 判官+变体账本流水线，工程量小（选择函数与变异算子各约几十行）。其"10 代后多样性衰减"直接警告当前账本若无新颖度项会早熟收敛。
