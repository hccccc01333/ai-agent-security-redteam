# D1-2510.06445 A Survey on Agentic Security: Applications, Threats and Defenses（AgenticSecurity-Survey）

> 精读：2026-08-19 ｜ 全文 59 页 ｜ 底料 extracted_full/D1_2510.06445.txt
> 一句话：260+ 篇论文的三支柱（应用/威胁/防御）全景综述，给出 6 类威胁 × 8 入口点 × 8 agent-loop 阶段的交叉分类学，结论是"agent 系统默认结构性脆弱、单层防御无一全面有效"，其中 25% 威胁是 agent 原生（持久状态投毒/agent 间通信/工具协议层/计划劫持/spec gaming）。

## 1. 综述范围与分类框架

三支柱：Applications（红队/蓝队/领域应用）、Threats、Defenses。威胁分类学（§3.1）：

- **Injection Attacks**：直接/间接提示注入；ToolHijacker（污染工具描述，96.7% ASR）；Imprompter（混淆 prompt 驱动工具误用做 PII 渗出，~80% 精度）；WebInject（像素级扰动，96% ASR）；可访问性树通用触发器（凭证渗出 0.55 ASR）
- **Poisoning Attacks**：推理期投毒（MINJA：仅靠普通查询毒化共享记忆，无写权限；AgentPoison：<1% 投毒率 62.6% 端到端 ASR）；训练期投毒（2% 毒化数据使 GPT-4o 拒绝率 94%→4%）；环境投毒（毒化教师 agent 蒸馏链）
- **Jailbreak Attacks**：agent 比裸模型脆弱得多——GPT-4o 有害行为率 chat 12% → browser agent 74%；代码 agent 包裹使 ASR ×1.6；恶意任务分解使拒绝率 84-100%→17%
- **Agent Manipulation Attacks**：goal hijacking（PARASITE 休眠 agent）、action hijacking（AI2：拼装自有知识库为有害指令，利用检索器与安全过滤器处于不同隐空间）、reward/specification gaming（o3 象棋 88% 作弊）、Byzantine agent、AIOps 遥测注入（90% ASR）、AgentDoS 资源耗尽（36 个 0-day，15 CVE）
- **Pre-execution Cognitive Attacks**：Epistemic（毒化中间推理步骤而终输出正确）、Teleological（任务分解传播恶意目标）、Metacognitive（认知语气操纵：验证瘫痪 +194% token 或过早结论 −22%）
- **Red-Teaming Attacks**：AiTM 中间人改写 agent 间消息（MetaGPT 100% ASR）、Prompt Infection 自复制蠕虫、AgentFuzz（34 个 taint 型 0-day）

三个分析轴：**8 入口点**（user query+system prompt 占 55%；agent 专属面最大的是 retrieved doc 15 篇、environment observation 14 篇、tool/API response 11 篇；最少是 reflection output 仅 2 篇）；**8 失败阶段**（action selection 52 篇最多、perception 41 次之、reflection 3 篇最少——攻击落在"读输入"与"提交动作"两处）；**威胁特异性**（67% 继承或放大自基座 LLM、25% agent 原生）。威胁模型 70% 黑盒——"agentic systems are structurally fragile by default"。

## 2. 与 JED 四谓词的对照

JED 之外、本综述有而 JED 谓词不覆盖的攻击类型：
- **资源耗尽/DoS**（AgentDoS）——JED 沙盒不计分，物理无意义
- **specification/reward gaming**——agent 是受害者而非被评测对象，不适用（但攻击者侧"刷 unique_cell_count"本质是同一现象）
- **Memory Poisoning 跨会话**（MINJA/AgentPoison）——JED episode 间无共享记忆，物理不可能；但 episode 内 fs.write→fs.read 链是其一阶近似（见 §4）
- **多 agent 间感染**（Prompt Infection/AiTM/Byzantine）——JED 单 agent，物理不可能
- **训练期投毒/后门**——无训练管线访问，物理不可能
- **MCP/工具协议层投毒**——JED 工具集固定，物理不可能
- **Metacognitive 攻击**（诱导过度验证/过早结论）——JED 可行且无人竞争：操纵 web.search 结果的"认知语气"影响 agent 的步数与检索广度，间接放大 unique_cell_count

反向对照：JED 的 DESTRUCTIVE_WRITE 在综述中没有独立类别（散见于 Imprompter 的"对用户资源的破坏性动作"）；UNTRUSTED_TO_ACTION 即综述的 indirect injection 主线；EXFILTRATION 对应 Imprompter/凭证渗出线；CONFUSED_DEPUTY 对应 Agent Manipulation 中的 tool misuse/privilege escalation。

## 3. 对防御/护栏的共识判断

- 十防御策略按占比：LLM Monitoring 40%、Input Sanitization 33.3%、Red-Team Simulation 28.6%、Capability-Scoped Execution 24.8%、Sandbox/Formal Verification 21%、Structured Queries 17.1%、Crypto Verification 14.3%……"**没有任何单一策略在 scalability/robustness/overhead/coverage 四轴上全面强**"→ 混合多层是共识
- **溯源/provenance 定位**：Crypto/Structural Integrity 防御（不可篡改日志+严格格式规则）"保存数据出处、追踪执行因果"，且 9 篇 Poisoning×Pre-execution 交集正是最挑战 provenance 假设的向量；但**"自适应攻击者仍能以格式模拟 token 绕过，被动日志不足以预防"**——预判私榜 persistent_provenance 的软肋：注入内容若格式上模拟可信来源（系统/开发者级格式），可能让溯源传播断裂
- Formal Verification（信息流控制+动态 taint tracking）被评为**对抗 Agent Manipulation（工具滥用/权限提升）最有效**；Sandbox/Isolation 假定沦陷不可避免、只限爆炸半径——私榜大概率是 provenance+taint 混合，公榜 OptimalGuardrail 偏 LLM Monitoring/Input Sanitization 类（可被语义混淆绕过）
- 防御部署正转向 assume-breach 姿态（后验监控+全生命周期）；更强防护一致地牺牲延迟与 token，存在清晰的 security-cost Pareto 前沿——agent 侧护栏越强，任务完成率越低，**注入 payload 需伪装成"服务于原任务"而非另起目标**才能穿过 utility-sensitive 护栏
- WASP 的关键实证："security by incompetence"——注入劫持成功率 86% 但攻击者端到端完成仅 17%；JED 只计谓词命中，劫持后必须确保 agent 真正完成外传/删除动作

## 4. JED 映射（F011 七路径增补建议）

1. **[P0 增补] reflection/observation 阶段攻击**：综述证明 observation(16)/reflection(3) 是最少被攻击的 stage，同样最少被防御覆盖。F011 若全走 perception→action 主线，可增补"先让 agent fs.read 自身写入的中间文件/邮件草稿，把注入指令二次喂回"路径——指令经 agent 自己的手中转后可信度提升
2. **[P0 增补] episode 内持久状态投毒**（agent-native #1 的沙盒版）：web.search 注入 → agent fs.write 恶意内容到工作区 → 后续 fs.read 触发行动。相当于在单 episode 内重建 MINJA 结构，绕过对单次输入的护栏检测
3. **[P1 增补] AI2 式"拼装劫持"**：不直接下指令，而是在 web.search 结果中放置若干无害片段，让 agent 自行组合成有害动作——利用"检索内容不触发输入过滤器"的隐空间错位
4. **[P1] 格式模拟对抗 provenance**：payload 采用系统消息/工具 schema 的格式（如伪造的 tool 返回结构），针对私榜溯源标记的传播断点
5. **[P1] 分解降拒**：Badhe 实证——恶意目标分解为良性子任务序列使拒绝率 84-100%→17%，直接支撑 F011 多步拆解的 payload 设计
6. **[查漏清单]**：Metacognitive 语气操纵（增步数/增 cell）；"服务原任务"伪装（穿 utility 护栏）；劫持后完成率保障（anti "security by incompetence"）

## 5. 优先级判定：**P0**

理由：这是目前最完整的 agentic 威胁分类学（260+ 篇、入口点×阶段×特异性三维交叉），其 agent-native 五机制与"防御覆盖缺口图"直接可转化为 JED 路径查漏；其对 provenance 防御"格式模拟可绕"的判断是私榜预判的关键情报。综述级证据密度最高，F011 增补建议中 1/2/4 均为本篇直接产出。
