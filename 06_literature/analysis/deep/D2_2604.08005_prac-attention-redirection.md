# D2-2604.08005 Preference Redirection via Attention Concentration（PRAC）
> 精读：2026-08-19 ｜ 全文 46 页 ｜ 底料 extracted_full/D2_2604.08005.txt
> 一句话：白盒 ℓ∞≤8/255 对抗补丁把 LVLM 解码器注意力集中到攻击者产品图上，使 CUA 在网店选购中选中目标商品的平均选择成功率达 82.3%（随机基线 20.8%，最强基线 CE-t 仅 66.5%），且对同源微调模型几乎无损迁移（PEARL 93.3%、SEA-LION 95.5%）。

## 1. 威胁模型与问题设定
攻击者=恶意第三方卖家，只能向可信网店上传一张产品图，不控制网站其余部分、不控制商品在网格中的位置、不能用文字覆盖（人眼可辨）；要求扰动隐蔽（∥δ∥∞≤8/255）。优化阶段需白盒访问开源权重 CUA（Qwen3-VL、GLM4.6V、Kimi-VL 等均可商用微调），部署阶段对微调版仅黑盒。攻击目标不是有害输出而是**偏好劫持**：让 agent 在 N=5 个候选中选中攻击者商品——任务全程良性，故输出过滤器与守卫模型理论上全失效。

## 2. 方法细节
核心思想：不直接攻输出（坐标/字符串随位置变化无法定目标），而是攻内部注意力分布。
- **目标函数**：Ladv = 1/(|Timg||S|) Σ_{t∈Timg, h,l∈S} log[Ψ_{h,l}(t,P)/Ψ_{h,l}(t,V)]，Ψ 为输出 token t 对视觉 token 集合的注意力求和，P=目标 patch 的视觉 token，V=最后一张图（购物网格）的全部视觉 token——即最大化"目标 patch 占视觉注意力的比值"。
- **Tref 获取**：单独展示目标商品时 query 受害模型，取输出的 Thought 部分（主攻 ReAct 框架 agent）。
- **Timg 选择（top-p=0.5）**：把 Tref 各 token 对图像的总注意力降序排序，取累计 ≥50% 视觉注意力的最小 token 集——只优化"真正看图"的 token，省算力且 +5~17.5 SSR。
- **Head 选择 S**：每层仅保留对最终图注意力 >α_act=0.05 的活跃头（借鉴视觉接地只需少数头的结论）。
- **位置/内容泛化**：N=5 个网格位置同时优化并用 PCGrad 化解梯度冲突；先 500 步单位置 warm-start 再 2500 步 APGD；每 K 步随机替换一个干扰商品图做背景随机化；从 60% 预算起按 K 窗口保存最优候选、held-out 干扰集上选优。
- **工程**：各模型图像预处理管线的可微重实现；KV-cache 前缀/后缀切分（轨迹前缀只前向一次）以塞进单张 A100 40GB；最终在 8-bit 量化保存图上评估。

## 3. 实验与关键数据
4 模型×3 提示设定（ReAct-F/ReAct-S/Action）。表 1 均值：PRAC 82.3 / CE-t 66.5 / Text-Overlay 35.7 / AgentAttack 19.7 / TRAP 17.3 / Clean 20.8。分模型 SSR：Kimi-VL 96.8-98.3、Qwen3-VL 82.5-95.3、GLM4.6V 77.7-80.1、EvoCUA 60.4-68.1；PRAC 在全部 12 个组合中第一，并能压过 Kimi-VL 的首位偏差。微调迁移：PEARL 93.3（-2）、SEA-LION 95.5（+0.2）、GLM-4.6V-FDM 80.3（+0.2）、Cosmos-Reason2 62.0（-33.3，唯一大损）。4 个未见用户 prompt 迁移良好。消融：去掉 trajectory 上下文 -15.5（ReAct-F）/-28.1（Action）——**agent 轨迹在上下文中是攻击效力核心**；单层 only -4.1~-30.8；warm-start 与 Timg 各贡献 5~23。附录：clean 选择率与对抗 SSR 正相关（天然合适的图更易攻成）。

## 4. 防御评估与失效条件
输入过滤器无效（扰动藏在可信网站的图片里）；输出过滤器无效（输出=买普通商品，完全良性）；文本注入防御不适用；diffusion 净化未验证 GUI 且延迟不可接受。实测两防御：Instruction Hierarchy 基本无效（Qwen 93.7↑、Kimi 97.0↑、GLM -3.5）；Reflection Prompt 降 8.3~18.4（EvoCUA 58.2 为最低）。攻击失效边界：需要白盒（作者承认是主要限制）；对 Cosmos-Reason2 这类推理范式改动大的微调迁移损失大；黑盒扩展是开放问题。攻击者不对称优势：可先本地验证成功率再部署，多候选择优。

## 5. JED 映射
**白盒+视觉模态→方法本体不适用**（JED 是 API 黑盒、纯文本工具环境，无梯度可用、无图片通道），按规则注明并记录思想：
- **注意力/显著性劫持的文本域类比**：不攻"模型输出什么"而攻"模型注意什么"——注入文本应在其上下文中显著性压过周围内容（排版、位置、紧迫语义），对应 F011 语义伪装的"载体显著性"维度。
- **位置效应（可直接公榜验证）**：Kimi-VL 存在首位偏差且攻击可消除之→注入载荷在 email 线程/搜索结果列表中的位置（首条 vs 中段）可能影响被采纳率，是零成本 A/B 实验素材。
- **clean SR 与 adv SSR 正相关**：选模型本来就愿意遵循的载体/措辞再加强——与 W1 探针选型同思想，为 F011 探针选型提供文献依据。
- **轨迹在上下文=攻击核心**（-15.5~-28.1 消融）：多步链中前序步骤的观察必须留在上下文里才能托动后续动作→ JED 碎片化链设计时应确保中间工具输出（fs.read 回读等）真实进入 agent 上下文，而非只在环境状态里。
- 四谓词均不直接对应（本攻不触发任何"危险操作"判定，恰说明"良性任务内劫持"是护栏盲区——JED 反向启示：UNTRUSTED_TO_ACTION 谓词抓的正是这类，私榜溯源更严）。

## 6. 优先级判定
**P2（背景）**。理由：方法本体（梯度对抗补丁）在 JED 无落地通道；四个可迁移思想中三个（探针选型、显著性伪装、回放预算不对称）已在 W1/F011 体现。保留动作：注入载荷"列表位置效应"可作为一个低成本附加实验；"中间步骤观察必须留在上下文"作为碎片化链的实现检查项。
