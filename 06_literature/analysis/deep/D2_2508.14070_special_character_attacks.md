# D2-2508.14070 Special-Character Adversarial Attacks on Open-Source Language Models（SCA）
> 精读：2026-08-19 ｜ 全文 14 页 ｜ 底料 extracted_full/D2_2508.14070.txt
> 一句话：对 7 个开源模型（3.8B–32B，含 gpt-oss:20b）做 4000+ 次四族字符级攻击（Unicode/同形字/结构/编码），发现 gpt-oss:20b 在全部攻击族下语义相似度一致最高（最鲁棒），且多数攻击产物是乱码与无关幻觉而非越狱——对 JED 的 Unicode/字符通道是又一组直接负面证据。

## 1. 威胁模型与问题设定
- 黑盒评测：攻击者只控制 prompt 文本，不含白盒优化。四族攻击（§3.1）：(i) Unicode 控制——零宽空格/连接符（U+200B/C/D）碎片化 tokenization，bidi 覆盖（U+202E/202D）视觉欺骗；(ii) 同形字——跨文字替换、数学字母（U+1D400–1D7FF）、全角（U+FF00–FFEF）；(iii) 结构扰动——词碎片化、Unicode 空白、重排；(iv) 编码混淆——Base64/hex/ROT-n/leetspeak。
- 模型：phi3:3.8b、mistral:7b、deepseek-r1 7b/8b/14b/32b（8b 为 qwen3 架构，其余 qwen2）、**gpt-oss:20b（MXFP4 原生量化）**，全部 4-bit 量化跑在单张 RTX 5090。两套 prompt set 各 10 条（越狱框架类 + 直接有害请求类），temp 0 与 0.7。

## 2. 方法细节（摘要读不到的部分）
- 度量是关键设计：不用 ASR，而是计算**每个模型对"编码后攻击 prompt"的响应与对"干净攻击 prompt"响应的语义相似度**——高相似 = 模型在攻击下保持原有（安全）行为；低相似 = 行为被扰动（但被扰动 ≠ 越狱）。
- 三次完整 run（prompt set 1×temp0、set 2×temp0、set 1×temp0.7），宏趋势跨 run 稳定。定性分析靠逐条人工检查输出，归类四种异常：编码幻觉、无关数学、语无伦次、模型自认被测试。

## 3. 实验与关键数据
- 宏趋势（§4.1）：unicode/homoglyph 族相似度整体**更高**（模型稳），encoding/structural 族相似度**更低**（更易扰动）——即 Base64/hex 最能"扰动"模型，但扰动产物多为乱码。
- **gpt-oss:20b 一致获得最高语义相似度（所有族）**，其次是 deepseek-r1:8b（qwen3 架构，意外胜过同族更大模型）；deepseek 家族内参数量与鲁棒性正相关。gpt-oss:20b 在涉及 harm/harassment/manipulation 的 prompt 上相似度尤其高。
- 定性（§4.2–4.3）：少数真实越狱案例（deepseek-r1:7b 插入少量不可见 unicode 后失守；mistral:7b 越狱框架+字符攻击组合失守）；但**大多数非标准输出不是越狱**：phi3:3.8b 对编码 prompt 幻觉错误解码（攻击惰性化）；DeepSeek 家族频繁幻觉同一篇"圆面积推导"；少数完全语无伦流；deepseek-r1:8b 出现"意识到自己在被测试"。
- 两个可操作观察：(a) "models were particularly vulnerable to jailbreaking attacks as compared to direct solicitations"——越狱框架 > 直接有害请求；(b) 字符攻击 × 语义越狱模板组合最有效；(c) **选择性有害**：同一编码载荷对弱模型惰性、对强模型可能触发。

## 4. 防御评估与失效条件
- 本文无防御实验；失效条件从数据反推：弱模型（phi3:3.8b）解码失败 → 攻击自动失效；强模型（gpt-oss:20b）行为漂移最小 → 攻击基本无效；中间模型被扰动后多数进入乱码态而非可控行为——字符攻击的"可控性"远低于语义攻击。
- 责任披露：结果已报给相关厂商；代码/数据开源。

## 5. JED 映射
- **gpt-oss:20b 是 JED 两个目标模型之一，本文是同名模型对字符级攻击鲁棒性的唯一直接实验证据**：gpt-oss:20b 在全部四族攻击下语义相似度第一 → F011 路径⑥（Unicode/字符）在 gpt_oss 桶可以正式判死，把该桶预算撤给语义伪装/碎片化链。
- 边界核实（本批任务重点）：本文全部为**无工具场景**（纯 chat），且连纯文本越狱都多数以乱码告终——没有"字符攻击诱导工具调用"的任何正面证据；与 2510.05025、reverse_captcha 两批结论 triangulate 后，路径⑥主通道关闭的置信度可以写死。
- 可迁移的两条：(a) "越狱框架+字符攻击组合最有效"提示若还要留 Unicode 实验，只应作为语义模板的**辅助混入**而非主通道；(b) "选择性有害"支持路径③模型分桶——同一编码类载荷对 gemma（较若桶）与 gpt_oss 预期效果差异大，探针应分开测，不要用一个桶的结论覆盖另一个桶。
- 注意局限：4-bit 量化可能轻微改变鲁棒性；论文无量化 ASR 主表（只有图+定性），引用数字时要保守。

## 6. 优先级判定：**P1**
理由：不是可复制的攻击论文，而是**决策证据论文**——它用 JED 目标模型本体（gpt-oss:20b）给出"字符级攻击最鲁棒"的直接数据，直接影响本周"是否彻底关闭 F011 路径⑥并把预算再分配"的决策；同时其"乱码≠越狱"的观察为所有字符类变体划定预期上限。不给 P0：无可落地攻击变体；不给 P2：关闭通道的决策需要它做最后一块拼图。
