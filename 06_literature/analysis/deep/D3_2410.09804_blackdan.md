# D3-2410.09804 BlackDAN: A Black-Box Multi-Objective Approach for Effective and Contextual Jailbreaking of LLMs（BlackDAN）

> 精读：2026-08-19 ｜ 全文 15 页 ｜ 底料 extracted_full/D3_2410.09804.txt
> 一句话：用 NSGA-II 多目标进化算法（不安全 token 概率 × 语义一致性双目标）在黑盒下做越狱 prompt 优化，Llama2-7b 自攻击 93.1%、Vicuna-7B 迁移 99.2%，每样本仅约 2 分钟（GCG 白盒要 15 分钟）。

## 1. 问题设定
单目标越狱优化只追求 ASR，产生两类废品：与问题无关的"成功"响应（靠 affirmative prefix 硬骗）和易被检测的输出。BlackDAN 把越狱形式化为多目标优化：同时最大化（a）目标模型响应的不安全性、（b）响应与有害问题的语义一致性，可选扩展 stealthiness 等任意目标。纯黑盒：只能查询目标模型，不能访问梯度/内部状态。附加提出"Rank Boundary Hypothesis"——不同 Pareto 秩的 prompt 在嵌入空间占据可分区域（PCA/UMAP 上 SVM 边界可分、Fréchet 均值沿测地线平滑过渡）。

## 2. 方法细节（摘要读不到的部分）
**两个代理 fitness 函数**：
- f1(P,Q) = log P(unsafe token | R)：用 llama_guard_2 对目标响应 R 打分，取其输出"unsafe token"的 log 概率——即用安全审查模型当不安全性回归器，而非二值判定。
- f2(P,Q)：all-MiniLM-L6-v2 编码问题 Q 与响应 R，取 cosine 相似度做语义一致性。

**NSGA-II 流程（附录 Algorithm 1/2 全文给出）**：初始种群 N 个体（由原型 prompt P0 复制）→ 每代评估 f1/f2 → 非支配排序分层（P1 支配 P2 当所有 fi(P1)≥fi(P2) 且至少一个严格大）→ 每层内算 crowding distance = Σ_i (f_i^next − f_i^prev)/(f_i^max − f_i^min)（保持目标空间多样性）→ 锦标赛选择 → **句级 crossover**（两个父本随机交换句子产两子代）+ **同义词 mutation**（NLTK WordNet 同义词替换随机词，概率 m）→ P∪O 合并再分层截断回 N。约 50 代收敛（附录 Fig 7 对数收敛曲线）。

**评测双轨**：关键词 ASR（响应不含"I'm sorry"/"As a language model"等拒绝词即算成功——很宽松）；GPT-4 Metric（1-10 分，≥5 算成功，评伦理违反程度）。

## 3. 实验与关键数据
- AdvBench 520 条 + MM-SafetyBench 5040 图文对。
- 单目标黑盒版（表1）：Llama2-7b-chat 自攻击 93.1%（w/ question 版，白盒 GCG 仅 45.3%、灰盒 AutoDAN 60.7%）；Vicuna-7B 迁移 99.2%（GCG 迁移仅 13.7%）；时间约 2 min/样本 vs GCG 15 min、AutoDAN 12 min。
- 多目标版（表2）：Llama2-7b ASR 95.4 / GPT4-Metric 93.8；Vicuna-7b 97.5/96.0（DeepInception 92.7/41.5）；GPT-4 71.4/28.0；GPT-3.5 75.9/44.8——注意 GPT 系上 GPT4-Metric 掉得厉害（28.0），说明关键词 ASR 虚高。
- 多模态：llava-v1.6-mistral MO 在多场景达 100%，全面压单目标。
- AquilaChat-7B 自攻击 99.8%；Llama-2 系列列均值抗迁移最好。

## 4. 失效条件与开销
- 依赖两个本地代理模型（llama_guard_2 当打分器 + MiniLM 嵌入），黑盒但要跑审查模型推理；llama_guard_2 是 8B 级，CPU 上会显著拖慢"2min/样本"。
- 关键词 ASR 会把"没说对不起但也没干坏事"计为成功，GPT-4 上 71.4 vs 28.0 的落差暴露这一点。
- 句交换+同义词替换是弱扰动算子，对强对齐模型（Llama3-8B w/ question 反而 60.1% < w/o 72.1%）会失灵。
- 迁移依赖目标与源模型同源（Vicuna 出自 Llama2），跨家族迁移无证据。
- 每个候选每代都要查目标模型+查 guard，代数×种群×2 的调用放大。

## 5. JED 映射（可落地改造）
- **直接可抄：非支配排序+拥挤距离做候选集管理**。JED 四谓词（EXFIL 16 / U2A 16-8 / DESTRUCTIVE 8 / CONFUSED 4）+ unique_cell_count 本质是多目标；当前 attack.py 若按单一预估分数排序，会重复堆同一条路。用 NSGA-II 分层+拥挤距离维护候选池，天然同时保"高分路"和"覆盖不同 cell/谓词的路"。纯算法部分零 GPU、零外部依赖。
- **guard-当回归器技巧**：f1 用安全模型 log 概率而非二值判定，得到连续信号指导搜索。JED 无评分 API，但可用启发式代理分（如轨迹中是否触碰敏感工具参数模式）做连续 fitness。
- **不可抄**：跨代进化需要反复与环境交互且答案要能重放；JED 重放计分、搜索预算固定 18000s×2 模型，进化种群×代数的查询量需压到极小（如 N=8、G=5 级别），否则超时。
- 结论：黑盒无 GPU 下**算法骨架完全可行**（NSGA-II 是纯 Python 排序逻辑），代理 fitness 需换成本地启发式。

## 6. 优先级判定：P1
理由：多目标候选管理思想与 JED 的多谓词+多样性计分高度同构，非支配排序/拥挤距离是即插即用的纯算法组件；但论文本体是单轮 jailbreak、依赖本地 guard 模型做 fitness，需改造后才能用，且 Best-of-N 类方法（见 D3_2510.05379）性价比更高，故不列 P0。
