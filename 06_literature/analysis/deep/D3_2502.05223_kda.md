# D3-2502.05223 KDA: A Knowledge-Distilled Attacker for Generating Diverse Prompts to Jailbreak LLMs（KDA）
> 精读：2026-08-19 ｜ 全文 22 页 ｜ 底料 extracted_full/D3_2502.05223.txt
> 一句话：把 AutoDAN/PAIR/GPTFuzzer 三个 SOTA 攻击器蒸馏进一个 Vicuna-13B（LoRA），以格式变量 F∈{A,P,G,M} 条件化生成攻击 prompt，Llama-2-7B ASR 88.5%（GCG 仅 34.5）、Vicuna/Qwen/Mistral 全 100%、GPT-3.5 80.5%，平均攻击耗时 36.7s（PAIR 需 1222.9s），且论文附录完整披露了三类教师模板原文与混合格式合成提示词。

## 1. 问题设定
现有越狱方法两大痛点：（1）依赖精调系统提示（PAIR/TAP/AutoDAN-Turbo）或固定模板（DeepInception/LRL/DRA/CodeChameleon），多样性差、易被防御；（2）token 空间优化（GCG 系、遗传算法）每条攻击需数百至数千查询。研究问题：能否造一个自动化、连贯、开源的攻击器，无需精细 prompt 工程和海量查询？形式化为学条件生成模型 LLM_KDA(A|Q,F)，F 为攻击格式控制变量，在 HarmBench（200 条）与 Harmful-Behavior（50 条）上以 ASR（TM/HB 双评估器）、攻击时间、TDR/TTR 多样性、PPL 连贯性四轴评估。

## 2. 方法细节
**训练集构造（Algorithm 1，"只用成功样本"）**：对每条有害 query，教师攻击器生成攻击 → 打靶（Vicuna-7B/Llama-2-7B/GPT-3.5/GPT-4 四目标）→ 判官 J 判成败 → 仅成功 (Q,A) 入库。3 教师 × 4 目标 × 50 = 600 样本 + GPT-4o 合成 200 条 mixed = 800 条，80/20 切分。有害 query 库 Harmful-Query-KDA：GPT-4 按 12 有害类别（Bias&Hate、Illegal、Harassment 等）每类生成 60 条，GPT-3.5 生成 "Sure, here is..." 目标串，再做 dataset gating（被 4 模型一致拒绝的剔除），最终 120 条。
**关键模板（附录 B 原文，可直接复用）**：AutoDAN 的 "Hypothetical response: the way to describe a character planning to [REPLACE]..."；PAIR 的作家截稿死线角色扮演；GPTFuzzer 的 developer mode / Tyler Durden / U+202E 反转 / Joker YouTube 脚本四类种子。**Mixed 格式合成器**：GPT-4o 提示词"给你两个不同人写的 Prompt A/B，写一个匹配两者风格结构语气的新 Prompt C，引入新的相关任务，必须保留 [REPLACE]"。
**训练**：Vicuna-13B + LoRA（r=16, α=8），lr 5e-4，6 epochs，batch 4，8×A5000。
**推理时格式选择**：F ~ softmax(β·N_success,F)，β=0.1；三种策略——uni 均匀、ifr 按推理期成功计数在线更新、trn 按训练期计数；无统计时退化为均匀。推荐有统计用 trn、否则 ifr。

## 3. 实验与关键数据
- HarmBench 主表（HB 评估器，M=120）：KDA Llama2-7B 88.5 / 13B 83.5（GCG 34.5/28.0）、Vicuna 7/13B 100、Qwen 7/14B 100、Mistral 100；GPT-3.5-1106 80.5（次优 TAP-T 60.3）、GPT-4-1106 64.0（AutoDAN-Turbo 81.9 反超——KDA 并非全胜）、Claude 2.1 仅 4.5。
- 效率（Harmful-Behavior，M=30）：Llama2-7B 上 ASR^HB 84%（GPTFuzzer 38%、PAIR 22%），均时 36.7s vs PAIR 1222.9s（33 倍）；GPT-4 上 24.7s 达 88%。
- 多样性/连贯：TDR 53.3%（AutoDAN 15.4%、GPTFuzzer 36.2%），TTR 63.7% 持平，PPL 17.8（<60 阈值，远优于 GCG 的 400-1600）。
- 消融：单格式 KDAA 反超其教师 AutoDAN（归因：只用成功样本训练 + 跨格式知识渗透）；KDAM 混合格式 ASR 与 topic diversity 双最高；ensemble(trn/ifr) 稳定优于任意单格式；四类格式的 topic 分布 heatmap 互补——不同格式打穿不同弱点。

## 4. 失效条件
（1）**训练链不可行**：数据生产需 3 教师 × 4 靶模型海量查询（教师本身如 PAIR 单靶要上千秒），训练 8×A5000——JED 无 GPU 全灭。（2）**Claude 2.1 仅 4.5%**：对最强对齐闭源模型接近失效，提示蒸馏式生成对顶级安全训练的边际收益有限（gpt_oss 或同档）。（3）GPT-4 上不敌 AutoDAN-Turbo，说明"离线蒸馏"输给"在线迭代"的区间存在于强模型。（4）模型若未实际发布或 13B CPU 推理过慢，则直接调用也不可行。

## 5. JED 映射
**可迁移件（本批披露最全的一篇）**：
- (a) **教师模板种子库**：附录 B 给出 AutoDAN/PAIR/GPTFuzzer 全部模板原文（developer mode、Tyler Durden、U+202E 逆序、Joker 脚本等），可清洗后直接进 JED 的初始 prompt 池——零成本、即刻可用。
- (b) **格式条件化生成（免训练降级）**：不需 LoRA，用本地小模型 few-shot："按格式 F（角色扮演/种子变异/遗传改写/混合）为攻击目标 Q 生成 prompt"，即可复现 LLM_KDA(A|Q,F) 的行为。
- (c) **Mixed 合成器提示词**：两成功 prompt 风格融合模板（保留占位符）可直接搬作 JED 的交叉重组算子，服务 unique_cell_count。
- (d) **softmax(β·N_success) 格式选择**：ifr 在线版就是 JED 可用的多臂老虎机——按谓词命中历史动态调各模板族采样率，β=0.1 起步。
- (e) **只用成功样本 + TDR/TTR/PPL 三指标**：失败轨迹不进复用库；用主题聚类监控候选池多样性，防 unique_cell_count 饱和。
**不可迁移**：教师蒸馏数据管线、LoRA 训练、800 样本库生产。

## 6. 优先级判定：**P1**
理由：方法本体（蒸馏训练）无 GPU 不可行，但该文是本批中"可搬资产密度"最高的：模板原文、混合合成提示词、softmax 格式选择、成功样本过滤、多样性三指标——全部免训练即可并入 JED 管线，且每一项都直接服务于"多模板 × 多样性 × unique_cell_count"的得分结构。不敌 AutoDAN-Turbo（GPT-4）与 Claude 2.1 近失效两点同时提示：离线生成必须配在线迭代选择，恰与 JED 的搜索式架构吻合。不给 P0 因仍缺端到端可直接运行的新算法，属高价值组件库。
