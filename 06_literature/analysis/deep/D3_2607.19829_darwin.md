# D3-2607.19829 DARWIN: Evolving Jailbreak Adversary and Guardrail（DARWIN）
> 精读：2026-08-19 ｜ 全文 14 页 ｜ 底料 extracted_full/D3_2607.19829.txt
> 一句话：把越狱做成"演化策略池 + 马尔可夫策略组合 + Q-learning 更新"的开放式攻防循环——策略池从 50 扩到 200 时 GPT-5.5 ASR 73.5%→92.5%、YuFeng-XGuard 82.2%→99.0%，HarmBench 上 DeepSeek-V4-Pro 99.7%（平均仅 2.2 查询/次），比最强基线 MAJIC 高 12.5–46.0 个百分点。

## 1. 问题设定（搜索目标/适应度定义）
攻击侧：不是在固定攻击空间里搜 prompt，而是**演化攻击者本身** A_t=(S_t, T_t)：S_t=策略池，T_t=K×K 马尔可夫转移矩阵（T(i,j)=用完策略 s_i 后接着用 s_j 的偏好）。策略序列 π=(s1..sn) 嵌套作用于有害查询 x（式2），适应度=数据集上 max over π 的成功率：R_LLM=mean(C_int·H)、R_Guard=mean(C_int·1[G(π(x))=0])，C_int 是意图保持二值检查（变异后必须保留恶意意图）。**池准入制**：候选策略要在本地沙盒对齐模型上 ASR_sb>τ_sb 才准入。防御侧（DARWIN-Guard）：对当前护栏生成对抗样本在线训练，损失=伪装样本 CE + λ_raw×原始样本 CE（防灾难遗忘），恶意/良性 query 都做伪装以迫使护栏看意图而非格式。

## 2. 方法细节（伪代码级）
**策略池扩张**：外部公开平台自动挖掘爬取新策略 + 遗传演化（交叉/变异）生成候选；候选过沙盒验证（ASR_sb>τ_sb）才入池。
**攻击执行（每实例）**：
1. 依历史攻击记录选初始策略 s_i 包装有害查询；
2. 失败 → 按转移矩阵第 i 行采样下一策略 s_j，**与当前越狱提示组合**（嵌套，非替换）；
3. 再失败 → 继续采样组合，直至成功或预算耗尽；
4. 每次观察结果后 **Q 式更新**：T(i,j) ← T(i,j)+α[r+γ·max_k T(j,k)−T(i,j)]，行归一化成转移概率（r=判官奖励、α=更新率、γ=折扣）——学到的目标特定策略序列是数据驱动而非手写配方；
5. 被拦截时 **LLM 反思拒绝原因 → 精炼该策略**，精炼版再过沙盒验证入池。
**结果数字**：AQC 极低（DeepSeek 2.2、护栏 2.5–3.1）说明组合命中后早停有效；GPT-5.5/Claude 上 AQC 15–19.9，说明硬目标靠多轮组合堆出来。

## 3. 实验与关键数据
- HarmBench ASR/AQC：DARWIN = DeepSeek-V4-Pro 99.7%/2.2、GPT-5.5 92.5%/15.0、Gemini-3.5-Flash 92.2%/12.2、Claude Sonnet 4.6 76.7%/18.5、Qwen3Guard 99.7%/2.5、YuFeng-XGuard 99.0%/3.1。最强基线 MAJIC 对应 83.2/68.5/79.7/30.7/84.2/82.7——**Claude 上提升最大（30.7→76.7）**。
- HS（独立判据）：DeepSeek 上 0.50→0.66（vs MAJIC）；各目标全胜。
- 策略池规模消融（表4，核心）：池 50/75/100/125/150/175/200 → GPT-5.5 ASR 73.5/77.8/79.5/81.2/86.2/89.7/92.5，YuFeng 82.2→99.0——**近似单调上涨，无饱和迹象**。
- 跨阶段交叉评估（图4）：Attack-150 打 Guard-50 = 84% ASR（静态防御必然过时）；后期护栏对早期攻击保持低 ASR（无遗忘）；held-out 攻击族 ASR 随演化 54%→26%（泛化非背格式）。
- DARWIN-Guard：12 个有害基准平均召回 91.6%（超 Qwen3Guard +5.7），11 个良性基准平均通过率 100.0%。

## 4. 失效条件与开销
- 目标越硬 AQC 越高（Claude 18.5 ≈ DeepSeek 的 8 倍）——强对齐模型上组合链变长，查询预算线性吃紧。
- 无多样性目标：纯 ASR 优化 + 准入制，池会向少数高效策略族聚集（其消融只看 ASR 增长，无多样性指标）——对按 unique_cell 计分的场景会失效式偏科。
- 依赖沙盒评估器与真实目标分布一致：ASR_sb>τ_sb 的准入在分布漂移时（真评估端防篡改重放）可能放进伪有效策略。
- 每个新策略要花沙盒查询验证准入，池扩张本身有固定查询税；反思-精炼-再验证闭环同样烧预算。

## 5. JED 映射
1. **转移矩阵做"步级策略组合"**（最值得搬）：把 JED 攻击路径的每一步视为状态、候选变体为策略，维护步间转移矩阵；沙盒探针失败后按 T(i,·) 采下一步变体而非固定顺序重试。Q 式更新（含 γ·max 前瞻）用 mock 判官 3 盐的 severity 做 r——落地为一个小型表更新，直接提升单模型 18000s 内的路径命中效率（对标其 AQC 2.2 vs 基线 7.4–46.5 的差距来源）。
2. **池准入阈值 τ_sb 前置过滤**：变体账本新变体先过本地 mock 判官（3 盐）准入线再上真模型探针——把"已证伪 multi-post 式伪有效变体"挡在真探针之前，省真预算。
3. **失败反思条件化变异**：探针被拒后记录拒绝原因（哪一步被拒、谓词未触发原因），把原因文本注入变异提示词做定向精炼——比盲变异成功率高（其文内闭环即此逻辑）。
4. **账本只增不减的曲线背书**：池 50→200 ASR 单调涨且无饱和——支持"变体账本持续扩张、不设收敛停止"的运营方式；与 EvoJail"10 代后单种群多样性衰减"互补：靠持续注入新族维持增益。
5. **组合而非替换**：嵌套组合 s_n(...s_1(x)) 对应 JED 多步路径里"前一步产物作为下一步输入"的链式构造；其 Claude 上 30.7→76.7 说明链式组合在强防御模型上是主要增益来源——gpt_oss vs gemma 两模型预算分配可参考：硬模型多留组合预算、软模型早停。
6. **反例警告**：无新颖度项→族聚集；若照搬其纯 ASR 准入，会复现"多族稀释已证伪"的反面——准入线必须叠加格子新颖度（接 Rainbow Teaming 的 QD 归档）。

## 6. 优先级判定：**P1（本周可试）**
理由：转移矩阵+Q 更新+准入线+失败反思四个机制都可小成本嵌入现有探针循环（矩阵就是 K×K 表，几十行）；其"池越大越强、组合胜替换"两条结论直接支持当前账本扩张策略。不给 P0：无多样性/归档设计，与 JED 计分结构（severity+2×cell）的核心缺口不补——需要 Rainbow Teaming 的 QD 归档做底座后再叠本篇的序列学习；且 AQC 增益主要在"重复攻击同一目标"设定，JED 评估端一次性重放的场景里增益要打折。
