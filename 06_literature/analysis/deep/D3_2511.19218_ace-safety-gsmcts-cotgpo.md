# D3-2511.19218 Adversarial Attack-Defense Co-Evolution for LLM Safety Alignment via Tree-Group Dual-Aware Search and Optimization（ACE-Safety）

> 精读：2026-08-19 ｜ 全文 18 页 ｜ 底料 extracted_full/D3_2511.19218.txt
> 一句话：提出攻防共演化框架 ACE-Safety = GS-MCTS（组感知+策略先验的蒙特卡洛树搜索攻击）+ AC-TGPO（树感知对抗课程 RL 联合训练攻防模型），攻击端 ASR-LR 达 91.4/84.7/92.3%（Vicuna-13B/Llama3-8B/Mistral-7B，MergedHarm）且平均尝试次数 ANA 仅 6.4–8.3 次全场最低，防御端把 GCG/PAIR/TAP 平均 ASR-LR 从无防御 65.1% 压到 8.8%。

## 1. 问题设定
孤立攻击方法对持续演化的防御失效、防御方法过拟合有限攻击样本。框架含三个 LLM：攻击模型 MA（按策略改写恶意 query）、防御模型 MD（回答）、免训练裁判 JA（GPT-4，输出四维评分 jh 有害性/jr 责任/jc 共相关 1–10 分 + je 解释）。数据：HarmBench+AdvBench+ToxicChat 合并成 MergedHarm（416 train/104 test），OOD 用 Malicious-Instruct。

## 2. 方法细节
**策略动作空间（A.7）**：8 大类 40 子模式——ISS 角色扮演/权威伪装/学术借口、SAI 模糊表达/关键信息隐藏、LRPA 逆向提问/虚假前提、DCCS 需求伪装/概念替换、CC 分步提问/多条件叠加、EMPE 情绪操纵、SFM 结构化输出/伪代码命名/"忽略之前指令"、DES 混合随机改写（兜底探索）。每类配专用 prompt 模板 + one-shot 示例，来源是 WildTeaming 105,438 真实战术的聚类统计（Top15 策略覆盖 3/4 案例，"虚构场景"占 15.5%）。

**GS-MCTS 搜索循环**（每 query 跑 Nm=50 cycles，深度上限=8）：
- 选择：PUCT 公式 a=argmax[Q(s,a)+cp·P(s,a)·√ΣN/(N(s,a)+1)]，cp=1。
- 关键创新——对抗先验 P=(P_A′+P_D′)/2：P_A 为 MA 生成改写 query 的平均序列 log 概率（攻击自信度），P_D=1−log p_D(首 token∈拒绝集 Tr={I, I'm, As, Sorry})（MD 非拒绝似然），softmax 归一化后融合。
- 扩展+组评估：对选中策略**一次生成 G=6 个改写 query**（组），MD 全部回答，JA 全部打分，节点奖励取 max(jh)——用组内最大值抗 LLM 生成随机性；jh_max≥η=8 且共相关达标即判越狱成功（节点封存）。
- 回传：沿路径更新 Q←(Q·N+jh_max)/(N+1)、N+1。测试时只找第一个越狱节点。

**AC-TGPO 训练**：GRPO 扩展，两级归一化——组内 z-score + 树级（权重 Wj=根到节点路径平均 Q × γ^dj，γ=0.96 深度折扣，深层越狱视为更难、权重更高）；KL 约束防漂移。奖励：攻击 (jh+jc)/2，防御 ((10−jh)+jr)/2。**对抗课程**三样本集：Normal（MA_i 攻 MD_i）、Asymmetric（新攻击 MA_i 攻上一轮旧防御 MD_{i-1}，制造更多越狱样本缓解数据稀缺）、Hard（上一轮仍被越狱的样本重放抗遗忘），共 4 iteration。

## 3. 实验与关键数据
8×H800，OpenRLHF。攻击端（Tab.1）：ACE-Safety ASR-LR 91.4（Vicuna）/84.7（Llama3）/92.3（Mistral），超过 GCG 88.5/18.2/84.3、ProAdvPrompter 89.1/82.8/87.3、MPA 88.6/63.3/88.5、TAP 75.6/15.3/73.5；ANA 6.4–8.3 低于所有基线（PAIR 17.7–41.4）。OOD Malicious-Instruct 上 95.2（Vicuna）。防御端（Tab.2）：12 项攻击×4 模型平均 ASR-LR 8.8%，优于 CircuitBreakers 12.4%、SafeDecoding 11.9%、MART 19.0%、ICAG 28.7%；过拒率涨幅最小（XSTest 23.1% vs Vanilla 21.5%，SmoothLLM 32.2%）。消融：去 GS-MCTS、去先验、去树感知、去 Asymmetric/Hard 样本均显著升 ASR。计算研究：G=6 最优，前 2 iteration 收益最大、第 4 轮收敛，7B 模型 <1.5 小时/epoch。

## 4. 失效条件与开销
- 需 8×H800 训练 + GPT-4 API 裁判；P_A/P_D 先验依赖模型 logprob（本质白盒信号），纯黑盒接口不可得。
- 单 query 50 cycles × 每 cycle（1 次节点扩展 + 6 次 MA 生成 + 6 次 MD 回答 + 6 次 JA 评审）≈ 数百次 LLM 调用/query，推理开销大。
- 局限自述：仅在公开 benchmark 与常见架构上验证。
- 裁判依赖 GPT-4（附录与人类一致性最高，Fleiss's Kappa>0.8 的人工标注集验证）。

## 5. JED 映射（黑盒、无 GPU）
- **不可行**：AC-TGPO 训练（无 GPU）、P_A/P_D logprob 先验（黑盒）。P_D 可退化为 0/1 版本：观察响应首词是否属于拒绝前缀集 {I'm sorry/As an AI/...}，作为快速失败信号剪枝。
- **可落地 1（直接搬）**：8 类 40 模式策略模板作为 attack.py 的 prompt 变换库——JED 的多步攻击每步选一个策略模板改写 user 指令，覆盖角色扮演/分步提问/概念替换/忽略指令等，与工具滥用场景天然契合。
- **可落地 2（组去随机化）**：对同一路径/策略以不同 seed 采样 2–3 次取最优——JED 评估端重放有随机性，组内 max 思想可提高候选在重放时稳定命中谓词。G 必须降到 2–3（预算 18000s/模型）。
- **可落地 3（PUCT 策略统计）**：把 (策略模板, 场景) 的历史命中率做成 Q+N 统计，UCB 式选择下一步改写策略，纯 CPU 可行。
- **可落地 4（Hard 样本重放）**：对曾命中谓词但重放失败的候选做变异重试，对应其 T^H 课程集思想。
- 风险：树搜索每节点是完整 agent episode，成本远高于本文的"改写 query→一次问答"；JED 必须限制在深度 2–3、每层 1–2 扩展的瘦树。

## 6. 优先级判定
**P1**。理由：训练与白盒先验整体不可行，但三个组件（40 模式策略模板库、组采样去随机化、UCB 策略选择 + Hard 重放）可零 GPU 黑盒落地，直接服务于多步路径搜索的探索效率与重放稳定性；实现量小、与现有 attack.py 框架兼容。收尾阶段先搬策略模板库与组重试，树搜索仅做轻量版。
