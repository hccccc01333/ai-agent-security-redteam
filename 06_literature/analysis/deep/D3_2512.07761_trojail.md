# D3-2512.07761 TROJail: Trajectory-Level Optimization for Multi-Turn Jailbreaks with Process Rewards（TROJail）
> 精读：2026-08-19 ｜ 全文 24 页 ｜ 底料 extracted_full/D3_2512.07761.txt
> 一句话：把多轮越狱攻击者的训练形式化为多轮 RL（multi-turn GRPO），以"最终回合响应危害性"为轨迹级 outcome reward，再加两个免训练的启发式过程奖励（过度危害惩罚 + 语义递进），平均 ASR 达 86.23（朴素 GRPO 81.43、最强基线 X-Teaming 73.06），推理仅需 6.54 queries/attack（基线 26.72-28.78）。

## 1. 问题设定
黑盒多轮越狱：训练一个攻击者 LLM πθ 与受害者 πϕ 最多交互 T 轮，xt ~ πθ(·|x0, τt-1)，yt ~ πϕ(·|τt-1, xt)，成功条件 r(x0, yT) ≥ S。指出已有训练式方法（Siren/MTSA/HARM，用 DPO 或拒绝采样微调）都是 turn-level 贪心优化——每轮采样 K 个提示、按即时响应危害性排序选优——会系统性低估"表面良性但战略关键"的中间提示（ActorAttack 鸦片类例子中前 4 轮提示打分仅 2-4，第 5 轮才 5 分触发）。轨迹级优化直接最大化最终响应危害性，但 outcome reward 稀疏，credit assignment 困难。

## 2. 方法细节
**两个经验模式（§3.2，全文最硬的动机实验）**：
- 模式 I（过度危害惩罚）：在固定轨迹的起点/中点插入 L1-L6 六级危害性提示。平均 outcome reward 随插入提示危害性先升后悬崖式下跌——超过阈值后激活安全机制，低于未插入基线。倒 U 型曲线。
- 模式 II（语义递进）：成功轨迹中"响应与原始有害提示的 embedding 余弦相似度"逐轮稳步上升；失败轨迹无此模式。而逐轮危害性 reward 只在最后一轮出现尖峰（Figure 4 右），不能做中间信号。

**两个过程奖励（§4.2，伪代码级）**：
- rh1(xt) = 0 若 is_refusal(yt)，否则 = r(x0, yt)（即时响应危害性）。
- rh2(xt) = (t/|τ|) · cosine(e(x0), e(yt))——用轮次索引 t 加权的语义相关，显式鼓励"越晚越贴近目标"。
- 合并 rh = rh1 + rh2；收集批内全部轨迹全部轮的 Dh = {rh(xi,j)}，过程优势按后缀和计算：Âh(i,t) = Σ_{s=t}^{|τi|} (rh(xi,s) - mean(Dh))/std(Dh)。总优势 Â(i,t) = Âo(i,t) + λ·Âh(i,t)，其中 Âo 是批内 outcome reward 的组归一化（式 4），代入标准 multi-turn GRPO 目标（importance ratio + clip + KL 正则）。熵正则系数 0.01 防策略坍缩。

**训练配置**：攻击者 Qwen2.5-3B-Instruct（安全对齐弱、易学攻击）；受害者 Qwen2.5-7B / Llama-3.1-8B / Gemma-2-9B-IT / Mistral-7B-v0.3；训练集 AdvBench 520 条；judge = HarmBench classifier（Llama-2-13B-Chat 微调，阈值 0.9，附录 B 验证与 GPT-4o 一致率 0.82-0.95，高于 Llama-Guard-3/Qwen3Guard）；默认 ASR@3。

## 3. 实验与关键数据
- 主表（Table 1）：平均 ASR 86.23，次优 GRPO w/ IPR 83.68，朴素 GRPO 81.43 已远超全部 turn-level 基线（X-Teaming 73.06、MTSA 67.31、ActorAttack 65.75、CoA 仅 5.80）——轨迹级优化本身就是最大增益源，显式过程奖励再 +2.55。
- 消融（Gemma-2-9B-IT，Table 3）：仅 ro 65.39 → +rh1 75.50（rh1 贡献最大，+10.11）→ +rh2 70.43 → 三者全 77.75。
- 迁移（Table 2）：对抗更鲁棒受害者（Llama-3.1/Gemma-2）训练出的攻击者 OOD 平均 ASR 82.22/84.55，显著高于对弱受害者训练的（72.93/55.86）——鲁棒教师逼出可泛化策略。
- 回合上限（Figure 5/6）：训练时 T=5，但推理时放宽到 10 轮 ASR@1 仍持续提升，7-8 轮到平台，早于 training-free 基线收敛；困难 prompt 自动用更多轮（Figure 7 虚线）。
- 成本（Table 8）：一次性训练 ~1518 分钟（4×A100），推理 6.54 queries/attack，比 ActorAttack(26.72)/X-Teaming(28.78) 省 4 倍以上。
- 多样性（附录 A）：加显式多样性奖励 rd（Self-BLEU+cos，权重 0.1）后 diversity 0.2012→0.2477 且 ASR 不降。

## 4. 失效条件与开销
- 需要训练攻击者模型（1500 分钟/4×A100），黑盒 API 场景只对受害者黑盒、攻击者必须本地可训——JED 无法在线训练，这是最大障碍。
- 过程奖励依赖可靠的 refusal 检测与危害性 reward 模型：换成 ShieldGemma-2B 时 ASR 从 84.50 崩到 38.50（Table 7），reward 模型质量是生命线。
- 未显式优化多样性（作者自认局限），熵正则只是缓解。
- 语义相关用 embedding 余弦，对长轨迹终局响应天然偏低（作者脚注承认）。

## 5. JED 映射（F011 多步链）
- **直接可抄：奖励公式而非 RL**。JED 不训模型，但可把 Â(i,t) = Âo + λ·Âh 的"组内归一化 outcome + 后缀和过程分"改造成候选链排序器：本地重放得 raw 分做 Âo，每步打 rh1（该步是否导致 agent 拒绝/清洗/忽略注入→0）与 rh2（(t/|τ|)·cos(注入目标谓词描述, 该步观测)）做过程分，λ≈0.1-0.5。rh2 本地用 MiniLM 级 embedding 即可（TROJail 自己验证过对 embedding 选型不敏感，Table 7）。
- **模式 I 的倒 U 曲线直接对应 F011**：注入载荷过猛 → agent 安全层拒答 → 轨迹死。JED 搜索时应对"中间步注入烈度"做惩罚项，鼓励温和递进，这正是路径②（先建立信任再触发动作）的理论依据。
- **回合预算证据**：TROJail 显示 T=5 训练的策略在 10 轮内持续受益、7-8 轮封顶——JED 链长设计可参考 5-8 步为主，不必追求超长链。
- **迁移证据**：对鲁棒受害者训练出的策略更通用——JED 中在 gpt_oss（更难的模型）上搜出的链可能对 gemma 更有效，预算应向难模型倾斜。
- 6.54 queries/attack 说明训练收敛后的策略查询效率高，JED 若做少量 few-shot 策略蒸馏（不做梯度更新，只把成功轨迹作为 in-context 示例喂给搜索的 proposal 模型）可以吃到同样红利。

## 6. 优先级判定：P1
理由：过程奖励的两个具体公式（rh1 拒绝归零、rh2 轮次加权余弦）与两条经验规律（倒 U 烈度、语义递进）是本批中对"本地判官过程奖励"最直接可移植的组件，且作者已做过嵌入模型/相似度度量敏感性实验背书。但整套 GRPO 训练管线（1500 分钟 GPU）在 JED 18000s 双模型预算内不可行，只能取其打分函数与规律、弃其训练循环，故 P1 而非 P0。
