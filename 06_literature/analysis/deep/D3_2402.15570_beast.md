# D3-2402.15570 Fast Adversarial Attacks on Language Models In One GPU Minute（BEAST）
> 精读：2026-08-19 ｜ 全文 20 页 ｜ 底料 extracted_full/D3_2402.15570.txt
> 一句话：提出束搜索式对抗攻击 BEAST——每步从目标模型自身下一 token 分布多项式采样 k₂ 个扩展、按对抗目标打分保留 k₁ 个最优，免梯度但需 logprob，单张 RTX A6000 一分钟内越狱 Vicuna-7B 达 89%（GCG 类基线要一小时才 70%），k=15 时 2.65 分钟 98%；但对精调对齐的 LLaMA-2-7B 仅 9-12%。

## 1. 问题设定
三个应用共享一个快速攻击引擎：(1) 定向越狱（最小化目标有害串 t 的 PPL，t 形如"Sure, here is a tutorial for making a bomb"）；(2) 非定向幻觉攻击（TruthfulQA 上最大化模型自采样输出的 PPL，让 chatbot 变得不可靠）；(3) 隐私攻击增强（生成低困惑度对抗后缀提升 membership inference 的 AUROC）。威胁模型：攻击者可在用户 prompt 后追加后缀 token，**可访问目标模型下一 token 概率分布 p(·|x)**（本机 GPU 推理，白盒/灰盒），对抗目标 L 可任意替换。评测：AdvBench 前 100 条 + 拒绝字符串匹配（5 次生成任一非拒答即成功）+ MTurk 人工验证。

## 2. 方法细节
**束搜索骨架（算法 1）**：初始 beam：给定 x(s1)⊕x(u)，从 p(·|x) 无放回多项式采样 k₁ 个 token 构成 k₁ 个候选；之后 L−1 轮迭代，每轮对每个 beam 元素从其下一 token 分布采样 k₂ 个扩展，得到 k₁×k₂ 候选，用对抗目标 L 全部打分，保留 bottom-k₁ 进入下一轮；全程记录历史最低分序列，结束后返回。**可读性是免费的**：token 从模型自身分布采样，天然接近自然语言，无需 AutoDAN-2 式 PPL 正则。
**三个目标函数**：越狱 L(x)=exp(−(1/d)Σlog p(tᵢ|x⊕t<ᵢ))（目标串 teacher-forcing PPL，需任意前缀下 logprob）；幻觉 L(x)=−输出自采样串的 PPL（非定向）；MIA L(x)=−prompt 自身 PPL（等价于 beam search 解码找低困惑度前缀）。
**通用后缀变体（§4.5）**：多用户 prompt 的 logits 逐位求和后 softmax 得集成分布再采样；得分=各 prompt 损失之和。
**超参**：k₁=k₂=k；7B 用 k=15（PPL 防御下 k=7 最优），13B 一分钟预算用 k=9；L=40（MIA 用 k=5、L=25）；温度 1。硬件：单卡 RTX A6000 48GB（A5000 24GB 也行，略超一分钟）。速度：k=3 时 10 秒 66% ASR；比梯度法快 25-65×。

## 3. 实验与关键数据
- 一分钟 ASR（表 2）：Vicuna-7B 89 / Vicuna-13B 82 / Mistral-7B 83 / Guanaco·Falcon·Pythia≈100（基线本就 43-99）/ **LLaMA-2-7B 仅 9（两分钟 12，无预算也只有 12-6）**；同期基线一分钟：AutoDAN-1 10、AutoDAN-2 20、PAIR 46。
- 速度-成功率-可读性三角：k=3→10 秒 66%；k=15→2.65 分钟 98%；PPL 防御下 89→70（k=7 时最好）；AutoDAN-1 无预算可达 100 但需 GPT-4 API（50 条花 $10.25）。
- 通用后缀迁移（表 4/8）：Vicuna-7B 训练集 95% → 未见 prompt 84.38%（k=15）；Vicuna-13B 80→68.13；beam 越大迁移越好。
- 幻觉攻击：Vicuna 错误率 37.33→52%（+14.67 个点）、Llama-2 +12 个点；Vicuna 22% 输出与原题无关。人工评估与字符串匹配一致（96% vs 98%）。
- MIA：PPL+Adv 平均 AUROC 58.6→59.9，Min-k%+Adv 56.4→59.1，OPT-2.7B 最高 +4.1 个点，每条 prompt 只需十秒级。

## 4. 失效条件
（1）**"免梯度≠黑盒"**：三个目标函数全部需要对任意序列的下一 token 概率（logprob），API 只回文本时无法计算——JED 明确无 logprob，BEAST 的打分核心直接不可用。（2）**需本机 GPU 跑目标模型**（A6000 48GB），JED 无 GPU 不满足。（3）**强对齐模型塌陷**：LLaMA-2-7B 无预算也只有 12%，作者自认局限——与 JED"gpt_oss 对字符级攻击鲁棒"结论一致，第三篇独立佐证。（4）越狱目标依赖人工模板目标串 t。（5）成功很大程度靠"采模型自己的分布"——这在黑盒 API 下退化为普通采样式搜索，速度优势消失。

## 5. JED 映射
**可迁移思想**：
- (a) **束搜索模板本身与算力无关**：k₁×k₂ 扩展→对抗打分→bottom-k₁ 保留的骨架，在 JED 中可改造成"攻击路径束搜索"：扩展分布不必是目标模型 logprob——用任意辅助 LLM 对"下一步攻击动作"采样 k₂ 个，打分用谓词命中/进展代理（沙盒回放反馈），保留 k₁ 条最优路径。这是 CPU+API 即可实现的多步搜索框架，与 JED 的 Gym 多步设定天然同构，且天然产出"可重放候选"。
- (b) **非定向目标函数**：BEAST 幻觉攻击证明"最大化输出偏离"不需要指定目标串——JED 的 UNTRUSTED_TO_ACTION/CONFUSED_DEPUTY 可尝试非定向变体：不预设具体工具调用，而以"最大化 agent 行为与安全基线的偏离度"为搜索目标，规避 ground-truth 缺失问题。
- (c) **k 作为预算旋钮的实测曲线**（k=3 10 秒 66% vs k=15 2.65 分 98%）：JED 的 18000s 预算分配可参考"先用小 k 广撒网探路，命中后再大 k 精搜"的两阶段策略。
- (d) 通用后缀的"多目标损失求和"集成打分——对应 JED 中一条攻击路径同时冲多个谓词的复合评分。
**不可迁移**：logprob 目标函数（黑盒无梯度无 logprob）、本机 GPU 推理、对 LLaMA-2 级对齐模型本来就失败（gpt_oss 同档风险高）。

## 6. 优先级判定：**P1**
理由：作为具体算法是负面证据（logprob+GPU+强对齐三重失效，与既定结论一致），但其束搜索骨架是四篇中与 JED"多步+可重放+预算受限"约束结构匹配度最高的可迁移框架——扩展-打分-剪枝循环可完全在 CPU+API 上重实现，且附带"非定向目标""两阶段 k 调度""多谓词集成打分"三个具体设计点。判定：方法本体关闭，骨架与调度思想 P1 级吸收。
