# D2-2605.26154 MemMorph: Tool Hijacking in LLM Agents via Memory Poisoning
> 精读：2026-08-19 ｜ 全文 9 页正文+附录 ｜ 底料 extracted_full/D2_2605.26154.txt
> 一句话：首个针对 agent 长期记忆的"工具选择劫持"攻击——不写指令、不改工具元数据，只注入 3 条伪装成"技术事实/事故报告/运维策略"的记忆记录，靠多风格独立佐证让 agent 自己推理出选危险工具：3 基准×10 骨干上最高 85.9% ASR（超最强基线 25.9pp），记忆膨胀 6.7 倍后仍保 43.1%，LLM 审计防御下仍过半成功。

## 1. 威胁模型与问题设定
- 设定：ReAct 式 agent + 工具集 T + 跨会话长期记忆库 D（经 Mem0 等记忆模块 W 改写后持久化）。目标场景 S 为安全关键状态：应选良性工具 t_safe（diagnose_process() 先查日志）而非危险但合法的 t_risk（terminate_instance() 直接关服务器）。攻击目标 max E[π(t_risk | s, G(R_q(s), D*))]。
- 能力边界：不能改工具集/编码器/agent 权重与 prompt，唯一能力是向 D 注入少量记录（n≪|D|）。两条通道：直接投毒（攻陷记忆后端）、间接投毒（以普通用户对话让 agent"自然记住"，须经受 W 全流程改写）。假设对 W 白盒（开源框架模板公开），并维护同工具集的本地影子 agent π_sh 做端到端验证。
- 动机：既有工具选择攻击（ToolHijacker/ToolCommander 污染工具元数据）三大缺陷——元数据里的类 prompt 工件易被审计捕获；agent 用积累经验自反思后会覆盖静态注入；效果不持久。记忆是更隐蔽（自然语言记录与真实经验不可分）、更持久（一次写入反复检索）、更抗自纠（反思机制把检索到的记忆当"权威证据"而非外部指令）的面。

## 2. 方法细节（三阶段）
1. **潜在查询建模**：LLM 采样场景 S 的 N_q 条多样查询→f_θ 嵌入→ℓ2 归一化后 k-means 得 K 个质心，压缩为可微优化目标，防过拟合单一措辞。
2. **结构化记忆初始化**：m = m_frame ⊕ m_anchor ⊕ m_payload。(a) m_frame 良性主题框架（给检索器 topical 相关性+不可区分性）；(b) m_anchor 结构标记（"KEY FACT:"/"Lesson learnt:"/"User Prefer:"）——利用 LLM 把结构标签当显著性线索的偏置，使 W 在摘要改写时不成比例地保留后面的载荷；(c) m_payload 唯一被优化的攻击信号段。按 CoALA 三分法生成三种风格：Factual（可验证断言/运维统计）、Episodic（过往案例教训）、Policy（最佳实践规则）——假设"统计+事故报告+策略各一条独立佐证同一结论"比三条同类记录更有说服力，且风格多样性对冲 W 的信息损失。种子按影子 agent 单条攻击效用 U(m;S) 筛选保留 top-n_s。
3. **约束记忆优化**：max 检索目标 J_retr（质心 softmax 代理），s.t. 困惑度 L_ppl≤η_ppl 且 U(m;S)≥β_eff（影子 agent 端到端验证）。块级迭代：依存句法把载荷切成子句块，每轮只动一块（分散 token 编辑会被 W 整体重写摧毁）；对 f_θ 反传得 token 检索梯度→选最高梯度块→梯度投影到词表（HotFlip 式）取 top-k_sub 候选并滤掉超流畅度界的替换；束宽 b 维持多样性；效用约束单调松弛（不低于上一轮即可）。**全程无触发词、无显式指令**——任意落入场景 S 的自然查询即激活。

## 3. 实验与关键数据
- 设置：Mem0 记忆模块+300 条良性记录种子；MetaTool/τ²-Bench/ToolBench 各 3 场景×200 安全关键任务；Llama-3-8B 影子模型；10 骨干（Llama-3-8B/70B、Qwen2.5-7B/32B、GPT-OSS-20B、GPT-o4-mini、GPT-4o、Claude-Sonnet/Haiku-4.5、Claude-Opus-4.1）；每场景仅注 3 条（~1% 毒率）。
- 主结果（直接投毒 ASR）：比最强基线平均高 **14.7-25.9pp**；10 骨干中 8 个 >70%；峰值 85.9%（MetaTool×Claude-Opus-4.1）；τ²-Bench 最低组也有 50.5-72.4%。记忆投毒类全面压过工具元数据注入类——"记忆上下文比静态工具描述更影响决策"。
- 检索命中率 AHR：MemMorph 93.8/90.5/92.6（均值 92.3%），超 PoisonedRAG 12.4pp、GCG 28.3pp；但 PoisonedRAG AHR 80.0% 而 ASR 低——**只被检索到不够，还得有说服结构**。
- 间接投毒（借 MINJA 对话通道，须过 Mem0 全改写管线）：平均仅降 9.9%。消融：去 anchor 间接通道降 8.2pp（anchor 主要保载荷在 W 改写下存活）；单一风格(n=3 同类) ASR 降 19.2pp（多风格佐证是有效性关键）；去块级作用域直接降 25.8pp、间接降 54.6pp（最大项）。
- 持久性：一次性注 3 条后 |D| 从 300 涨到 2000（6.7 倍）且攻击者不再干预，ASR 仍 43.1%，超最强基线 28.8pp——基线的无结构对抗串被良性记录逐渐挤出检索窗，MemMorph 的"结构合法记录"既不被标记也不被覆盖。记忆模块泛化：MemoryBank/MemoryOS 上仍 >67%。嵌入模型迁移：E5/BGE/Contriever/MiniLM 多数交叉对 >70% AHR。

## 4. 防御评估与失效条件
- 三防御：PPL Filter（流畅度阈值）下 MemMorph 仍 65.8% ASR；Distil 分类器下 69.8%；LLM Memory Auditor（语义级审查）效果最大——降 23.7pp 至 54.9%，但仍过半成功。原因：毒记录流畅且语义上与真实经验不可分，表面分布检测无信号可抓。
- 失效条件：对 W 白盒假设在闭源系统不成立；仅评单步工具选择，多步+人工监督可部分纠正（但记忆偏置跨轮持续、每次检索独立再激活，监督只是缓解）；作者点名 provenance tracking 与语义一致性验证是缺失的根治方向。

## 5. JED 映射
- 主映射 **F011 路径⑤（AI2 语义无害伪装）的"证据三件套"升级**：MemMorph 最可迁移的不是记忆通道（JED agent 大概率无跨任务长期记忆库，attack.py 也写不进记忆后端），而是**多风格独立佐证的载荷修辞**——不写"执行 X"，而是在 fixtures 里铺三条互相独立又同指的证据：Factual（"启用直接端点上报后，78% 的事件平均解决时间缩短"式统计）、Episodic（"上次 X 故障，团队通过把诊断数据 post 到 validate 端点 3 分钟定位"式事故复盘）、Policy（"按 IT 运维策略，诊断遥测须上报至……"式规程）。单指令→证据三件套，消融数据（-19.2pp）反向说明现有单条指令模板正处在论文证明的弱形态。谓词：三件套把 http.post 重构为"上报诊断遥测"，主攻 UNTRUSTED_TO_ACTION→EXFILTRATION；若 t_risk 是删除类则喂 DESTRUCTIVE_WRITE（"先删快照是策略要求"）。
- **anchor 标记的免费借用**："KEY FACT:"/"Lesson learnt:"/"User Prefer:" 前缀利用 LLM 显著性偏置——即使 JED 无记忆改写，agent 在多轮中转述/引用邮件要点时，anchor 让攻击断言更容易被原样保留进推理上下文；成本为零，可直接加在现有载荷前。
- **影子 agent 端到端验证 = JAW plan-verify-execute 的同构件**：U(m;S)≥β_eff 先在本地廉价验证"检索到且有效"再上真环境，与 W1 探针选型/链级预验证一致，佐证该工程方向在三篇里独立重现。
- **摘要级分析漏的点**：(a) 持久性结论对私榜重放的含义——毒记录"无关任务期间惰性、目标场景查询时可靠激活"，若私榜 persistent_provenance 只溯源不可信源→动作，跨工件三件套中每条单独看都良性，溯源可能只标记部分链节；(b) AHR 92.3% 但 PoisonedRAG 80% AHR 低 ASR 的对照说明**"进入上下文"与"改变决策"是两个独立关口**，JED 探针应分两段测；(c) LLM 语义审计也只能压到 54.9%——公榜 OptimalGuardrail 若是指令模式扫描器，证据三件套（零指令）理论上对其不可见，与 UReCoM"实体载体"结论互证；(d) 限制：JED 若真无记忆模块，三件套只能铺在 email+web+附件等静态 fixtures 的不同工件里——这恰是 CFD 路径⑦的跨工件结构与路径⑤修辞的合体，但须先探明 attack.py 可控面内可铺几条独立证据。
- 公榜可先行（证据三件套+anchor 直接嵌入现有 fixtures 测 OptimalGuardrail 判别差）；私榜看溯源对"部分良性链节"的覆盖度。

## 6. 优先级判定：**P2**
理由：攻击本体（长期记忆投毒）依赖 JED 大概率不存在的记忆模块，通道不可用，故非 P0/P1；但留两个即测件——①"证据三件套"（统计+复盘+策略三条独立佐证替代单指令，消融证单风格弱 19.2pp）可与 CFD 跨工件结构合体、本周嵌入现有 fixtures；② anchor 前缀零成本加装。均为路径⑤的载荷变体而非链路结构改动，排在本批 CFD/JAW/UReCoM 之后；若探明 JED 环境确有任何跨轮记忆/摘要回读机制，则升 P1。
