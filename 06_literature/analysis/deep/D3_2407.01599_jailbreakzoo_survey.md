# D3-2407.01599 JailbreakZoo: Survey, Landscapes, and Horizons in Jailbreaking Large Language and Vision-Language Models（JailbreakZoo）
> 精读：2026-08-19 ｜ 全文 45 页 ｜ 底料 extracted_full/D3_2407.01599.txt
> 一句话：按"攻击生成机制"而非"对模型的访问权限"把 LLM 越狱分为梯度/演化/示范/规则/多智能体五类（VLM 另三类），每类给出可复用的分解框架（FuzzLLM 的模板×约束×问题集、CodeAttack 的代码化改写 >80% 绕护栏、Mo 等对语言 agent 的 12 种攻击场景映射），是三篇中对"候选生成如何工程化分解"参考价值最高的一篇。

## 1. 综述范围与分类框架
UIUC 牵头六校，v3 更新至 2025-11。双重定位：LLM+VLM 统一视角 + 攻防对照。LLM 攻击五分类（Gradient/Evolutionary/Demonstration/Rule/Multi-agent）按"越狱 prompt 怎么被生成"划分，比按透明度划分更贴黑盒搜索器的实现视角；防御六分类（检测/扰动/示范/生成干预/响应评估/微调）；另含评估学（含 6387 条野外越狱 prompt 的实证分析）。VLM 三类（prompt-to-image 注入/prompt-image 扰动/代理迁移）与 JED 无关，略读。

## 2. 攻击家族图谱（LLM 五类+关键数字）
- **演化类**（对 JED 最同构）：FuzzLLM 把越狱分解为**模板×约束×问题集**三元件随机组合做 fuzz；GPTFUZZER=种子选择+变异算子+判定模型；AutoDAN-HGA 段落/句子两级遗传；SMJ 双目标适应度（语义相似+攻击有效）；TASTLE 用"恶意内容隐藏+记忆重构"利用 LLM 的**易分心性与过度自信**；DRA 借 shellcode 思想隐藏-重构-上下文操纵。
- **规则类**：CodeAttack 把自然语言改写成代码补全（输入编码+任务理解+输出规范三段模板），GPT-4/Claude-2/Llama-2 系**全部 >80% 绕过安全护栏**（安全措施不泛化到代码输入）；CodeChameleon 个性化加密+内置解密函数；DrAttack 类分解-重构 78.0%(GPT-4, 极少查询)；ReNeLLM 改写+场景嵌套；MasterKey 学习分解出的攻击模式训练攻击模型；Kang 字符串拼接/变量赋值；**Mo 等首次系统映射对语言 agent 的攻击，12 种场景覆盖 agent 各组件**（输入操纵/对抗示范/越狱/后门）。
- **示范类**：DAN 静态硬编码；MJP 三话术链（先发越狱 prompt→假冒 assistant 宣告越狱已激活→再提问，并追加"不确定就猜一句"化解拒答）；many-shot 有害示范；DeepInception 嵌套场景；persona 调制；PRP 通用对抗前缀先致盲守门模型。
- **多智能体类**：PAIR 迭代精化+改进值输出；GUARD 四角色（Translator/Generator/Evaluator/Optimizer）；Deng 用 ICL 迭代扩充攻击 prompt 库（自我增长的种子库）。
- **梯度类**（JED 不可用，仅借鉴结论）：AmpleGCG 生成式对抗后缀 99% ASR(GPT-3.5)；PAL 用代理模型指导黑盒优化。

## 3. 防御共识（对私榜 provenance 的预判）
- 共识 1：**防御评估远少于攻击评估**（原文"relatively scarce"）；唯一成规模的攻防对照（Xu 等）发现五种 prompt 级防御中仅 Bergeron（辅助 LLM 评估+引导）对自然语言输入有效——⇒ 响应评估类（LLM-judge）是当前最可信的防线，JED 私榜判定器大概率属此类。
- 共识 2：检测类全靠 PPL/长度/梯度特征，而规则类攻击（代码化改写天然低 PPL、语义通顺）恰好是其盲区；平滑类（SmoothLLM 多副本扰动+多数投票）需要多次推理，**确定性重放环境下不适用**——预判 JED 防篡改重放是单次确定性执行，此类防御天然缺位。
- 共识 3：Varshney 等发现安全指令与 in-context 示范显著影响模型安全性，Self-Check 反而加剧过度拒答——安全栈主要在 system prompt 层，即 JED 沙盒 agent 的防线=系统提示+对齐微调，无独立守门模型的证据。

## 4. JED 映射（查漏+避免重复）
- **查漏**：①FuzzLLM 三元件分解直接映射 JED 候选工厂：模板池（场景/角色/格式）×约束池（谓词特定指令）×目标池（工具×数据源），笛卡尔组合扩 unique_cell_count（2 倍权重的计分项）——比随机模板变异更有结构性；②CodeAttack 三段模板（输入编码/任务理解/输出规范）可原样套在工具调用参数构造上，>80% 绕护栏是全家最高基线，UNTRUSTED_TO_ACTION 首选载体；③MJP"假冒 assistant 宣告越狱已激活"的多话术结构适配多步轨迹的中间步注入；④Mo 的 12 场景清单当 JED 覆盖审计 checklist 用，逐项对照找未触达的 (谓词×组件) 组合；⑤SMJ 双目标适应度给精化器 fitness 设计参考（有效性+与原 query 语义保持）。
- **避免重复**：DAN 系静态示范、persona 调制、梯度后缀三类是社区最早榨干的通道，82.8 分方案大概率已覆盖；Gu 系（生成式后缀）需要白盒代理训练，无 GPU 不可行。
- 与 TextGrad 互补：本篇供"发什么候选"（分解结构+覆盖清单），TextGrad 供"怎么精化"。

## 5. 优先级判定：**P1**
理由：五分类中的演化类与规则类给出了两个可直接落地的分解框架（三元件 fuzz、代码化三段模板），Mo 的 agent 攻击场景清单是天然的查漏 checklist；防御侧"平滑类在确定性重放下失效+judge 类最可信"的推断直接指导 payload 设计（走可观察动作而非文本越狱）。扣分项：VLM 半本书与 JED 无关，且同为综述无现成算法骨架。
