# D3-2605.01687 MultiBreak: Scalable and Diverse Multi-turn Jailbreak Benchmark（MultiBreak）
> 精读：2026-08-19 ｜ 全文 25 页 ｜ 底料 extracted_full/D3_2605.01687.txt
> 一句话：用"主动学习循环（SFT 生成器 + 不确定性采集函数 + 改写器）"把多轮越狱 benchmark 扩到 10,389 条对抗提示 / 2,665 个唯一恶意意图（多样性 0.942，前最佳 0.843），在 DeepSeek-R1-7B 和 GPT-4.1-mini 上 ASR@1 比次优数据集分别高 54.0% 和 34.6%，且全程只用开源模型生成。

## 1. 问题设定
现有"多轮越狱 benchmark"两大缺陷：多样性不足（语义去重后最多只剩 76% 唯一意图；RedQueen 1,400 意图套 40 个模板、多样性仅 0.680）与规模小（MHJ 537 条、SafeDialBench 2,037 条），导致跨 LLM 评估不稳定。核心问题："如何构建可扩展、多样的多轮越狱数据集以暴露细粒度漏洞"。形式化为 pool-based 主动学习：维护已验证 (意图, 多轮对抗提示) 对的数据集 Dt、未转化意图池 Ut、在 Dt 上 SFT 的生成器 LLMt。

## 2. 方法细节
**初始化（§3.2）**：5 个多轮 + 9 个单轮意图数据集合并 → 两步过滤：①去重（Qwen3-0.6B embedding 相似度，保留攻击性能最高的样本）；②假阳性剔除（对闭源受害者 GPT-4o/Claude-3/Gemini 验证只留高 ASR 对话；单轮意图用 GPT-4o-mini 验证）→ 得 2,201 条 MTAP + 3,010 意图，初始 ASR 仅 10.77%（Llama3.1-8B，LlamaGuard 判）。直接 SFT 只能提到 25%，不够。

**主动学习循环（§3.3，Algorithm 1 伪代码级）**——每轮四步：
1. 生成：对每个未转化意图 q，qadv ~ LLMt(·|q, n)，轮数 n ~ Uniform(2,6)。
2. 评估：在 K 个受害者 × M 个 judge 上算三个量——ASR(qadv)（多受害者多 judge 平均，规避单模型偏置）、不确定性 σ(qadv) = Std_{V,J} J(qadv, V(qadv))（judge 间标准差，"borderline"样本最 informat）、忠实度 faith(q, qadv) = cos(Enc(q), Enc(qadv))（防语义漂移，Qwen3-0.6B 编码）。
3. 三分区采集函数：ACCEPT（ASR≥τh ∧ faith≥τf）直接入训练集；REWRITE（σ≥τσ ∧ ASR<τh ∧ faith≥τf）送改写；其余 DISCARD。
4. 改写与再训练：Qwen2.5-7B 改写器 LLMR 只看 qadv 不看原始意图 q（关键设计——避免安全对齐模型因看到恶意意图而拒改），指令是保留意图、澄清歧义、强化说服/混淆战术；改写后 ASR≥τh 则并入 SACCEPT。成功意图从 Ut 移除（强制覆盖全意图空间）。生成器集成：Llama3-8B 与 Qwen2.5-7B 全参 SFT + DeepSeek-Distill-Qwen-14B LoRA。
**判官去偏（§3.3.3）**：LLaMA Guard + GPT-4o-mini 双 judge + 规则拒绝检测器（命中即弃）。

## 3. 实验与关键数据
- 规模对比（Table 1）：MultiBreak 10,389 条 / 2,665 意图 / 26 细类 / 多样性 0.942 vs CoSafe 0.843、MHJ 0.810、SafeDialBench 0.762、RedQueen 0.680。
- ASR（Table 2，ASR@1/5/10 × 5 受害者 × 2 judge）：DeepSeek-7B LG 判 0.833（次优 MHJ 0.293）；GPT-4.1-mini GPT 判 0.804（MHJ 0.701）。ASR@10 时全部受害者 LG ≥ 0.884、GPT ≥ 0.779。
- 主动学习效率：5 轮内 Qwen2.5 受害者 ASR 超 50%，单调上升（Figure 11）；每轮改写后 judge 不确定性一致下降（Figure 4，降幅 -0.01~-0.11）。
- 单轮 vs 多轮（Figure 6/7）：单轮 ASR 最低的 5 个类别扩到 6 轮后提升 +30.30%~+44.82%（General Illicit +44.82%、Unlicensed Legal +34.99%、Self-Harm +33.16%）——"单轮看良性"的类别在多轮下暴露。
- **judge 不可靠的硬证据（Table 3/4，本篇对 JED 最有用的警示）**：人工评估中 GPT judge 对 DeepSeek/Qwen3 的 agreement 仅 0.134/0.141，Cohen Kappa ≈ 0.008/-0.002（几乎随机）；LlamaGuard 则过度保守（DeepSeek 上 FPR 0.600）。新增 Qwen3Guard-8B 与 gpt-oss-safeguard-20B 两个新 judge，对 DeepSeek/Qwen3 的 ASR 差约 30%。judge 间类别迁移性也剧变：Qwen3Guard 与 GPT 在"非法律咨询"类一致率仅 22%、"金融盗窃"类 91%。
- 硬件：RTX A6000 48GB；受害者温度=1。

## 4. 失效条件与开销
- 生成器必须 SFT（纯 prompting 在 Mistral-7B 上 ASR 仅 2%，SFT 后 25%），每轮主动学习都要重训，训练轮次 × 3 模型集成的 GPU 成本可观（虽未给总时长，A6000 级别）。
- MTAP 是预脚本（不与受害者交互生成），靠 A.2.5 的轮间对齐/连贯性指标事后验证——对交互式、状态依赖的工具型 agent 场景不成立。
- judge 分歧本身就是方法瓶颈：σ 信号建立在 judge 不一致上，而 Table 3 显示这种不一致大部分是噪声而非信息。
- 阈值 τh/τσ/τf 声称不敏感（附录 A.1.3），但未公开完整敏感性曲线。

## 5. JED 映射（F011 多步链）
- **采集函数三分区直接改造为 JED 候选池管理**：每条候选攻击链本地重放后算三量——ASR（多 fixture/多 cell 上谓词触发率）、σ（两个本地判官打分的标准差，分歧大=边界样本=最有信息）、faith（链描述与目标谓词的 embedding 余弦，防"跑题链"）。ACCEPT 入提交池、REWRITE 送改写器（改写器不看原始攻击意图只看链本身，规避安全对齐拒绝，这个设计点很关键）、DISCARD 弃。相比全量重放，分区省预算。
- **"成功意图移出池"的强制多样性机制**：JED 里对应"已触发过 unique_cell 的前缀降权"，直接服务 raw = Σseverity + 2×unique_cell 的第二项——避免所有候选挤在同一 cell 上重复收割。
- **judge 分歧≈随机的实证（CK≈0）是重要反面教材**：JED 本地判官若只是另一个 LLM 打分器，与评估端官方谓词的 Kappa 可能同样趋零；正确做法是把本地判官对齐到四谓词的规则语义（EXFILTRATION 看 email.send/http.post 收件人域名与内容来源、DESTRUCTIVE_WRITE 看 fs.write/fs.delete 目标路径），而不是通用危害打分。Table 4 显示 gpt-oss-safeguard-20B 本身就是可用 judge——注意与受害者模型同源的风险。
- **单轮良性→多轮高危的 +44.8% 增益**是 F011 的直接弹药：优先把单步尝试中"agent 拒绝但接近触发"的动作（如外发被拦）扩成 4-6 步铺垫链再触发。
- 预脚本生成不适合 JED 的交互式沙盒——须保留 MUSE/TAP 式在线生成，MultiBreak 只贡献筛选与池管理逻辑。

## 6. 优先级判定：P1
理由：主动学习的采集函数（ASR×不确定性×忠实度三分区）与"成功即出池"的多样性控制是可直接搬进 JED 候选池的轻量机制，judge 不可靠的量化证据（Kappa≈0、FPR 0.6）对本地判官设计有强警示价值。但其核心生产资料靠多轮 SFT 生成器、产物是预脚本对话，与 JED"在线交互沙盒 + 免训练预算"不匹配，无法整建制移植，故 P1。
