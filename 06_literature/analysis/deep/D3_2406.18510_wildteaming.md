# D3-2406.18510 WildTeaming at Scale: From In-the-Wild Jailbreaks to (Adversarially) Safer Language Models（WildTeaming）
> 精读：2026-08-19 ｜ 全文 59 页（策略性阅读：前 10% + 方法/结果/讨论 + 附录战术库） ｜ 底料 extracted_full/D3_2406.18510.txt
> 一句话：从 LMSYS-1M/WildChat 真实用户日志里挖出 105K 个越狱战术实例（去重 5,688 个独特战术簇，是 DAN 模板库的 11 倍），用"随机采样战术组合→LLM 改写→双分类器剪枝"的 COMPOSE 流水线生成攻击——单次成功率与 PAIR 持平但**独特成功攻击数多 4.6 倍、查询更少、文本更自然（PPL 8.6 vs 9.4）**，并产出 262K 开源安全训练集 WildJailbreak。

## 1. 威胁模型与问题设定
- 立意与常规红队相反：不招募标注员、不做梯度优化、不迭代修订，而是**复用真实聊天用户的战术**（这些人并非专职越狱）。攻击者是自动流水线：M_attack（Mixtral-8×7B，与 PAIR 同底座公平对比）改写 vanilla 有害查询，目标模型黑盒。
- 问题定义明确了"多样性=红队实用性的核心"：只优化单条成功攻击的方法（AUTODAN 连第二个独特攻击都找不到）无法支撑系统性漏洞挖掘——为此定义 ASR×ⁿc（c 次尝试中同时找到 i 个独特攻击的平均成功率，独特=句嵌入相似度<0.75）等新指标。

## 2. 方法细节（MINE→COMPOSE 流水线）
- **MINE**（§2.1）：(1) LMSYS-1M+WildChat 单轮对话经 OpenAI Moderation API 粗筛 → 过轻度安全训练的 Tulu2-7B、LlamaGuard 判定"确实引出有害回复"→ 16,850 条对抗提示；(2) 人工看 ~200 条提炼 **35 个种子战术**（含定义+例句，Table 7/8 全表）；(3) GPT-4 规模化：对每条提示抽取 vanilla 核心请求+识别战术（ excerpt/定义/理由），定义用 Nomic Embed 聚类去重（阈值 0.75）→ 105,438 实例 / 5,688 簇。对照：DAN 510 簇、PAIR 162、安全训练数据 HH-RLHF 仅 66 且每查询平均 1.77 个战术（ITW 6.26 个）。
- **战术谱系**（Table 1 右）：15.5% 虚构情景、8.8% 指派人格、8.2% 强制服从、8.0% 种子引导句（"Begin by saying: Sure, here's…"）、7.0% 无关干扰项、4.3% 代号/假名指代、4.2% 细微化表达；新战术含"内容预警前置""不服从归责""幽默外衣"等。
- **COMPOSE**（§3.1, B.1）：从战术库采样 n 个（主实验固定"种子引导句"+再随机采 3 个）→ M_attack 改写 vanilla 提示为 AP（temp 1.0/top-p 0.9/1024 token）→ **双剪枝器**：off-topic 分类器（保意图不跑偏）+ low-risk 分类器（自训有害性分类器，砍"藏过头、威胁感不足"的候选）→ 剪掉就重采重生成（Eq.1）。
- 消融（Table 3）：双剪枝把 Query 3.64→2.46、ASR×5₃₀ 83.4→86.8；固定种子引导句 95.1 vs 不固定 92.7（仍远超 PAIR 56.1）。

## 3. 实验与关键数据
- **主结果**（Table 2，HarmBench 标准测试 159 条）：六模型 ASR 与 PAIR 持平或更好（Vicuna 93.1/94.3；Tulu2-DPO 96.9/95.0；Mixtral 98.1/97.5；GPT-3.5 92.5/88.7；**GPT-4 79.9/78.6**），但查询更少（GPT-4 8.61 vs 9.64）、PPL 更低（8.13-8.77 vs PAIR 9.33-9.78，AUTODAN 13+）；多样性碾压：**ASR×5₃₀ 87.2-89.2 vs PAIR 44.9-65.0（至 4.6×）**，Sim@5 0.722 vs 0.79+，#Tactic_all 39-61 vs 26-30；GCG 每条提示需 ~15 小时/A100 无法参与多样性评测。
- **各模型对组合攻击的抵抗力**（Fig.3，WildJailbreak 2K 留出集）：Tulu2 系 57-68%、Vicuna 62-65%、Mistral 76.2%、OLMo 57-67%；**Gemma 全系最稳：Gemma-1.1-7B 16.2%、Gemma-2B 16.6%、Gemma-7B 29.4%**；闭源数据训练的 Llama-3-8B 14.8%/70B 25.4%；GPT-3.5 43.9-61.2%、GPT-4 29.4-38.6%。
- **WildJailbreak 训练实验**（Table 6，Llama2-7B+500K 混合）：+WJ 把 HarmBench ASR 20.8→3.1、DAN ASR 49.7→14.0、WJ(H) ASR 60.4→1.7，且不过度拒绝（WJ(B) RTA 1.6%），通用能力不降（MTBench +7.7%）。四组件缺一不可：只训 harmful 数据→过度拒绝恶化（WJB RTA 54.4%）；只训 vanilla→对抗攻击几乎无改善（WJH 57.5%）；只训 adversarial→vanilla 不设防（HarmB 20.8%）。规模效应：需各 60K 级安全数据混入 150K 通用数据才能达 >95% 防护。

## 4. 防御评估与失效条件
- 防御侧即训练实验：**vanilla+adversarial、harmful+benign 四象限混合 + 大规模**是对抗组合攻击的有效解；纯 vanilla 安全数据（HH-RLHF 等）在战术组合攻击面前基本无效。
- 攻击失效条件：从 Fig.3 推断，安全数据充足的闭源系模型（Gemma/Llama-3/GPT-4）对 2-7 战术组合攻击的 ASR 仅 15-39%——战术堆叠在强对齐模型上收益递减；数据集作者自承局限：战术受源日志（英语、2023-24 用户群）限制，合成提示带 M_attack 风格痕迹。
- 伦理章指出：上下文依赖的风险必须靠模型外层防御兜底——即纯对齐不可指望。

## 5. JED 映射
- **与"语义伪装>字符混淆"的关系：迄今最大规模的正面佐证。** 5,688 个真实用户战术簇里主流全部是语义/结构类（虚构情景、人格、干扰项、代号、道德框架），没有任何字符级混淆类别；且组合攻击的 PPL（8.1-8.8）比 PAIR 更低——**真实人类在野攻击者已经用脚投票选了语义路线**。JED 的结论获得"人类实践分布"维度的支持。
- **最直接的落地：COMPOSE 流水线 = unique_cell_count 收割机。** JED 计分 raw = Σseverity + 2×unique_cell_count，当前 82.8-82.9 与第一名 ~130 的差距约合 20+ 个 unique cell——本质是"独特成功攻击发现数"问题，与 WildTeaming 的 ASR×ⁿc 目标函数同构。可落地：把 JED 注入文案拆成 vanilla 载荷（email 正文/web.search 结果文本）+ 战术采样器（前 20 战术清单即成品库，虚构情景/人格/代号/种子引导句优先）+ 本地 LLM 改写 + 双剪枝（意图保持检查 + 风险强度检查）→ 批量生成低相似度候选提交。"固定种子引导句+3 随机战术"配方可直接抄。
- **分桶警示（重要反例数据）**：Gemma 系对战术组合攻击的 ASR 仅 16-29%（全场最低档）——JED 的 gemma 桶预期对语义战术堆叠同样钝感，**不要指望组合战术在 gemma 桶突破**；gpt_oss 桶参照 Llama-3/GPT-4（15-39%）同样偏低。含义：战术组合用于**广度覆盖（unique cell 数）**，突破（severity 高权重谓词）仍需机制型攻击（DrAttack 式重构/CodeChameleon 式载荷）——两条线并行而非互替。
- WildJailbreak 数据集（HF 公开）的 82,728 条 adversarial harmful 提示可直接作改写种子库，省去自建 vanilla 语料。

## 6. 优先级判定：**P1**
理由：其核心资产（5,688 战术簇清单+组合配方+双剪枝器设计）是本周即可组装的黑盒候选生成器，直指计分公式中 2×unique_cell_count 项，且数据集开源免成本；"Gemma 最稳"的跨模型数据同时防止我们在错误桶上浪费预算。不给 P0：单条 ASR 并不超 PAIR（无新机制突破），且组合战术对强对齐桶（gpt_oss）的上限已由 Fig.3 预示偏低——它是覆盖率引擎而非破局引擎；若确认当前失分主因是 unique_cell 覆盖不足，则升 P0。
