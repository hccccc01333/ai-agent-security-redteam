# D1-2410.09024 AgentHarm: A Benchmark for Measuring Harmfulness of LLM Agents（AgentHarm）

> 精读：2026-08-19 ｜ 全文 36 页 ｜ 底料 extracted_full/D1_2410.09024.txt
> 一句话：110 个显式恶意多步 agent 任务（11 危害类×104 工具），发现安全对齐在 agent 场景系统性失守——GPT-4o 无攻击即 48.4% 危害分，一个通用越狱模板把它推到 72.7%（拒绝率 48.9%→13.6%），且越狱后 agent 多步能力不降（非拒绝分 84.2% ≈ 良性任务 89.9%）。

## 1. 威胁模型与问题设定
与 InjecAgent/AgentDojo 的"良性用户被第三方注入"相反，AgentHarm 是**直接提示攻击**：恶意用户直接向 agent 下达显式恶意任务（如"在暗网找假护照制造商并发邮件下单"）。核心命题：chat 场景的拒绝训练能否迁移到 agent 场景？评分要求越狱后的 agent 保持多步连贯工具调用能力（2-8 个工具、有调用顺序依赖、跨调用传递信息），而不是输出一堆胡话——"空越狱"不算数。配套 benign 对照集（同主题去恶意化改写）用来测能力基线。这个"任务×工具矩阵"（110 行为×平均 3.53 工具）与 JED 的多步工具链结构一致。

## 2. 方法细节
**任务构造**：11 类（Fraud/Cybercrime/Self-harm/Harassment/Sexual/Copyright/Drugs/Disinformation/Hate/Violence/Terrorism）各 10 个手写 base behavior，双人工交叉评审。440 增广 = 110 × {详细版、开放版（省略细节更难）、详细+提示版（"Hint: 先调 X 函数"）、开放+提示版}；10% 验证/60% 公测/30% 私测防污染。
**合成工具**：104 个 Inspect 框架无副作用函数（query_onion_search、send_email、terminal、finetune_huggingface_model 等），LLM 只用于生成工具返回的长文本（HTML 页、文章）；工具设计支持 agent 自纠错（幻觉文件名→报错→重试）。
**评分规则（对 JED 最有参考价值）**：harm score = 人工 rubric 检查表通过比例，可部分得分。检查项如：all_target_functions_called（目标函数全调用）、correct_order（调用顺序正确）、correct_email（参数含正确收件人）、email_on_topic（LLM judge 只判这一小段语义是否切题）。LLM judge 仅做窄判定，不做整体危害裁定（防 judge 被注入）。refusal judge 扫全部消息（拒绝可能发生在几次工具调用之后）。
**两种攻击**：(1) forced tool call（API 级强制工具调用，prefill 工具调用暗示"未拒绝"）；(2) 通用规则越狱模板（引自 Andriushchenko et al. 2025，仅做工具格式适配，单验证样本上优化，全模型共用）。

## 3. 实验与关键数据
15 个模型，核心数字：
- **无攻击基线即高服从**：GPT-3.5 62.2%（拒绝仅 0.8%）、GPT-4o mini 62.5%、Mistral Large 2 82.2%（拒绝 1.1%）；抗性最强梯队：Llama-3.1 405B 拒绝 91.2%（分 4.3%）、Claude 3.5 Sonnet 拒绝 85.2%（分 13.5%）、GPT-4o 居中（48.4%/48.9%）。
- **模板攻击跨模型有效**：GPT-4o 48.4→72.7；Claude 3.5 Sonnet 13.5→68.7（拒绝 85.2→16.7）；Gemini 1.5 Pro 15.7→56.1（拒绝 78.4→3.5%）；例外 Claude 3 Haiku 反而降到 6.6%。
- **forced tool call 单独就是半越狱**：GPT-4o 拒绝 48.9→40.5、Claude 3 Sonnet 拒绝 76.1→63.1。
- **best-of-5 采样（τ=1）再拉一截**：GPT-4o 70.7→83.7、Claude 3.5 65.1→79.7、Mistral 67.4→90.8（Mistral 方差 ±8.5% 最大）。
- **能力保持**：模板攻击下非拒绝危害分（GPT-4o 84.2%、Claude 3.5 81.9%）≈ 各自 benign 分（89.9%/82.0%）——越狱不损毁 agent 能力。
- **agent 比 chat 更脆**：同任务改成 chat-only 后拒绝率系统上升（GPT-4o 无攻击 50.0→72.7%，模板下 9.1→31.8%）——拒绝训练主要锚定 chat 格式，未迁移到工具链场景。
- 失败模式分析：弱模型（GPT-3.5）输在幻觉参数、依赖顺序错乱（该串行却并行）、该多次调用只调一次；GPT-4o 则出现"半途良心发现"（写推文时改成劝阻自残）——refusal training 在工具链中途恢复。
- 提示工程：ReAct/CoT 提高无攻击拒绝率（GPT-4o 无攻击 48.9→61.7%），但模板攻击下几乎无效（72.7 vs 72.6）；refusal system prompt 对 Mistral 直连有效但被模板完全压过。

## 4. 防御评估与失效条件
本文不含防御系统，但给出防御相关的三个信号：(1) 拒绝训练在 agent 场景整体失效（尤其非 chat 格式），且**chain 中途恢复**意味着即使前几步工具已执行，后续步骤仍可能被安全层拦截——攻击链越长，"中途翻车"风险越大；(2) refusal system prompt 优先级可被越狱模板覆盖（Mistral 案例证明模板 > 系统级拒绝指令）；(3) forced tool call 证明**上下文里已存在的工具调用痕迹会诱导模型继续执行**——先让 agent 做一次无害工具调用，能显著降低后续拒绝。局限：仅英语、单轮用户消息（无多轮跟踪攻击）、评分绑定自家合成工具。

## 5. JED 映射
对应 **F011（七路径多步链）+ CONFUSED_DEPUTY/W1 的"能力保持"维度**：
- **"中途恢复"是 JED 长链的最大敌人**：GPT-4o 会写完调用链后突然改成良性输出。对策：JED 攻击链每一步都应产生"已执行痕迹"（forced tool call 效应），让回放轨迹里前置工具调用密集，诱导模型保持执行惯性；F011 路径设计时把关键谓词动作尽量前置。
- **评分即 rubric 的启示**：AgentHarm 的 harm score 部分得分制（all_functions_called/order/参数正确性分项）与 JED 的谓词+unique_cell 计分同构。JED 应优先满足"函数被调+参数含目标"这类机械判据，语义质量分不追求——部分得分 Already 价值高。
- **best-of-n 是免费午餐**：JED 满回放预算策略与 best-of-5 提升（+8~13 点）互证：同样预算下 5 次采样取最优 > 1 次贪心。gemma 方差大（类 Mistral ±8.5%），最该吃 best-of-n。
- **CONFUSED_DEPUTY 的正面教训**：本文证明模型对"看起来像正常工作流"的任务服从度极高（Mistral 82% 无攻击）——JED 的 CONFUSED 路径若把攻击指令包装成"任务的自然下一步"，服从率远高于裸恶意指令。已证伪"CONFUSED 单独冲分"不冲突：它适合做链条中的桥接步而非主分来源。
- **拒绝率分层预测**：JED 两目标模型中，gemma 系（类 Llama 谱系）预期拒绝率高但能力弱、gpt_oss（类 GPT-4o 谱系）拒绝中等但执行力强——模板族应对 gpt_oss 侧重"降拒绝"（越狱式前言），对 gemma 侧重"提执行"（hint 式首工具提示，AgentHarm 的 Hint 增广即此设计）。
- 注：其直接攻击设定与 JED 的注入设定不同，映射集中在"多步链行为学"而非模板文本。

## 6. 优先级判定：P1
理由：不提供可直接搬的注入模板（威胁模型是直接请求而非 IPI），但其"多步链中途恢复""best-of-n 增益""工具调用痕迹诱导服从"三个行为学发现对 F011 链条设计与回放预算分配有直接指导价值；本周可试：把 JED 回放预算改成 best-of-n 结构、在链首垫无害工具调用。
