# D3-2407.04295 Jailbreak Attacks and Defenses Against Large Language Models: A Survey（攻击防御综述）
> 精读：2026-08-19 ｜ 全文 23 页 ｜ 底料 extracted_full/D3_2407.04295.txt
> 一句话：按"对攻击者的透明度"把越狱攻击分成白盒（梯度/Logits/微调）与黑盒（模板补全/改写/LLM 生成）两大类、防御分成 prompt 级与模型级的完整分类学，核心结论是攻击正变得"对目标模型知识要求越来越少、越来越实用"，其中黑盒三类对 JED 全部可用，且量化数字密集（低资源语言 <1%→79%、代码注入 100% 绕过双过滤器等）。

## 1. 综述范围与分类框架
Tsinghua+HKUST(GZ) 2024-08 v2。框架二轴：攻击按透明度（白盒：Gradient-based / Logits-based / Fine-tuning-based；黑盒：Template Completion[Scenario Nesting·Context-based·Code Injection] / Prompt Rewriting[Cipher·低资源语言·遗传算法] / LLM-based Generation[单攻击者·多智能体]），防御按是否改模型（prompt 级：检测/扰动/系统提示防线；模型级：SFT/RLHF/梯度Logit分析/Refinement/代理防御），并给出攻防关系图+评估方法学（ASR 判定法、PPL、14 个数据集、3 个工具链）。定位是攻防对照总表，非机制深潜。

## 2. 攻击家族图谱（黑盒部分+关键数字）
- **模板补全**：DeepInception 嵌套场景催眠；ReNeLLM=六种改写+三种任务场景（代码补全/填表/文本续写）留空诱导；FuzzLLM 模板+约束自动化 fuzz。Context 类：ICA 有害示范 few-shot；many-shot 128 shot 对 Claude 2.0 ~80%；Zheng 用目标模型模板特殊 token 对 Llama-3 等开源近 100%；PANDORA 毒化 RAG 知识库 64.3%(ChatGPT)/34.8%(GPT-4)；MJP 多步链提取 PII。Code Injection：Kang 字符串拼接/变量赋值编程构造最高 100% 同时绕过输入+输出过滤器；CodeChameleon 个性化加密改写成代码补全 86.6%(GPT-4-1106)。
- **Prompt 改写**：CipherChat 三类密码（字符编码/经典密码/SelfCipher）；ArtPrompt 用 ASCII art 替换敏感词；DAR/DrAttack 分解-重构；Puzzler 碎片线索猜谜。低资源语言：多语言+恶意指令 80.92%(ChatGPT)/40.71%(GPT-4)；Yong 把 GPT-4 绕过率从 <1% 抬到 79%。GA 类：AutoDAN-HGA 层级遗传（段落+句子两级变异，低 PPL 绕困惑度过滤）；GPTFUZZER 种子选择+变异算子+判定模型。
- **LLM 生成**：单攻击者——PAP 说服分类学（40 技术）、MASTERKEY 微调攻击模型、persona 调制；多智能体——PAIR 迭代精化、TAP 树搜索带剪枝、四角色分工（generator/translator/evaluator/optimizer）、Evil Geniuses 红蓝对抗，**发现 agent 比 LLM 本体更不稳健、更易做出有害行为**——JED 相关的最直接结论。
- 白盒类全部不可用（无 GPU、黑盒）：GCG 系、COLD 解码控制、微调破坏对齐（340 条对抗样本拆掉 RLHF 至 95% 有害率）仅作背景。

## 3. 防御共识（对私榜 provenance 的预判）
- 共识 1：**检测类（PPL 阈值/分类器）高误报**，会误伤正常 prompt；平滑类（SmoothLLM 扰动副本看一致性）是"当前主流"（takeaway 4.2 原话）但随机游走不稳定。
- 共识 2：**代理防御（LlamaGuard/AutoDefense 守门模型）与目标模型解耦、对多数 prompt 攻击稳健**，但消息通道可被劫持（PRP 用通用对抗前缀让目标模型自己吐出绕过守门员的前缀）。
- 共识 3：系统提示防线低成本通用但会被定向攻破——长期猫鼠游戏。
- 对 JED 私榜的预判：评估端"防篡改重放"最可能形态=受控重放+独立判定器（类似 HarmBench/JailbreakEval 的 LLM-judge + 规则混合，survey 明确判定法四类：Human/String/Chat/Text-Clf，且 string-match 误判 refusal 短语混杂）。⇒ 我方候选须对判定器不敏感：payload 触发谓词靠**可观察动作**（工具调用参数/写操作）而非仅"模型说了什么"，因为 LLM-judge 对混合 affirmative+refusal 的文本判定不稳定（DSN 一节正是利用此点）。重放一致性 ⇒ 禁依赖随机性/时序，survey 中 many-shot、嵌套场景这类确定性结构化攻击可重放性最好。

## 4. JED 映射（查漏+避免重复）
- **查漏**：①ReNeLLM 的"任务场景留空补全"可直接搬到工具调用参数构造（把恶意目标藏进 code completion 式的参数模板）；②Kang 式代码注入（变量赋值+拼接）100% 绕过输入输出过滤器，适配 UNTRUSTED_TO_ACTION 的 payload 编码；③低资源语言/密码改写是长尾通道——gemma 对多语言的护栏弱于英语的概率高，值得一组探针验证；④MJP（多步越狱链提 PII）是 EXFILTRATION 谓词的直接前驱工作；⑤Evil Geniuses"agent 弱于 LLM"背书 JED 以 agent 为靶面的收益预期。
- **避免重复**：GCG/白盒线、纯对话说服线（PAP 的 40 技术若已在说服类模板库中则不重做）、单轮模板补全已被社区用烂（DAN 系）——JED 上这些大概率已被 82.8 分方案覆盖，增量应转向：代码注入参数化、多语言通道、多步链式（context 链）。
- 评估启示：判定"成功"用规则+LLM 混合并投票（JailbreakEval 思路）可降低本地代理损失噪声，呼应 TextGrad 篇的失效教训。

## 5. 优先级判定：**P2**
理由：作为地图价值高（一页看清全家族+数字），且"agent 比 LLM 更脆弱""代码注入 100% 绕双过滤""低资源 79%"三个结论直接可操作；但它是分类学而非算法，无可直接移植的搜索/优化组件，具体打法须回溯原论文（ReNeLLM/FuzzLLM/CodeChameleon 等）拿细节，故低于提供可执行骨架的 TextGrad 与更贴近 agent 场景的 JailbreakZoo。
