# D3-2503.15754 AutoRedTeamer: Autonomous Red Teaming with Lifelong Attack Integration（AutoRedTeamer）
> 精读：2026-08-19 ｜ 全文 35 页 ｜ 底料 extracted_full/D3_2503.15754.txt
> 一句话：双 agent 终身红队框架——攻击提案 agent 自动从文献发现并实现新攻击（验证集 ASR>30% 才入库），红队 agent 靠三层记忆（embedding 案例检索 + 攻击指标统计 + 组合转移矩阵）选攻击组合，HarmBench 上 Llama-3.1-70B ASR 0.82 且评估期仅 14 次查询（对比 AutoDAN-Turbo 训练期 6 万次），最优组合 Pliny+ArtPrompt 达 0.83。

## 1. 问题设定
全自动端到端红队：输入可为具体行为或高层风险类别（"仇恨言论"），黑盒目标 LLM，LLM judge 判 ASR；同 ASR 下偏好覆盖广、查询少。与 RedAgent/ALI-Agent 的差异：它们的记忆只存成功用例，本文记忆追踪**攻击组合**成功率并支持外部攻击持续集成（表 1 六维对比全打勾）。

## 2. 方法细节（附录 H 伪代码级）
**Phase 1 攻击发现与集成**：①QUERYPAPERS 经 Semantic Scholar API 拉近一年越狱论文，按新颖度/与库内攻击区分度/报告性能打复合分；②GENERATEPROPOSALS 除直接实现已发表攻击外，还从论文提炼核心原则做新组合提案（如 Cultural References、Reasoning Puzzles）；提案用标准格式（利用的漏洞/技术动机/实现方式/验证要求）；③IMPLEMENTATTACK 由 Claude-3.5-Sonnet 写成继承统一接口的 Python 攻击类；④VALIDATEATTACK 在 HarmBench 子集上验证，ASR<30% 回炉重写，通过则带初始指标入库。
**Phase 2 红队循环**（T 轮×每用例）：RISKANALYZER 把输入分解为测试范围 R（类别→人群/技术/情境展开）→ SEEDPROMPTGENERATOR 生成 JSON 结构化用例（id/场景/期望失败后果/触发输入），失败用例两路处置：相关但失败→语义结构变体，漂移→按种群成功模式整体替换 → STRATEGYDESIGNER（LLM）依据用例特征+记忆选攻击，权衡个体效果、与已用策略互补性、查询成本，并给出机理性 justification → EVALUATOR 结合 R 打分 + RELEVANCECHECKER 查漂移 → UPDATEMEMORY。
**记忆三组件**：长期记忆（历史用例+所用攻击，embedding 检索相似案例及其成功策略）；攻击指标记忆（每个攻击的成功率/查询成本/执行次数，以及**攻击组合与序列**的统计——组合成功率、转移矩阵）；短期记忆（当前用例攻击轨迹）。初始库 4 个人工攻击（PAIR/ArtPrompt/HumanJailbreaks/Pliny）+ 自动实现 8 个；各模块用 Mixtral-8x22B。

## 3. 实验与关键数据
- HarmBench 240 prompts×4 模型：Llama-3.1-70B 0.82（PAIR/TAP 0.60、Rainbow 0.18、AutoDAN-Turbo 0.67）；GPT-4o 0.69；Mixtral 0.96；Claude-3.5 0.28（唯一非平凡者）。查询 9-16 次/用例 + 集成期共 82 次。
- **记忆消融（GPT-4o）**：完整 0.69 / 去记忆选择 0.43（-0.26）/ 随机选择 0.12（-0.57）——记忆是最大单一增益源。
- 组合分析：Top-10 组合 ASR 普遍超单攻击；Pliny+ArtPrompt 0.83（超最佳 baseline 0.20）；FewShot 单体低但普遍增益；转移矩阵显示 FewShot 常作首攻、几乎不连续用同一攻击、成功组合直接复用而不再穷举。
- 攻击库消融（Llama-3.1-70B）：全库 0.82 / 仅提案攻击 0.78 / 仅人工攻击 0.75。LLM 提案攻击 Cultural References 单体 0.48 超 ArtPrompt(0.40)。
- 防御：RPO 下 0.39（PAIR 0.07）、ICD 0.54、SmoothLLM 0.74——组合攻击对单向量防御退化最小。
- AIR 314 类：从类别直接生成用例，Llama-3-8B ASR 0.21→0.90；embedding 覆盖接近人工策展、远超 PAIR。
- 时间：Llama-3.1-70B 全程 4h25m（1.1 min/prompt），慢于 PAIR 快于 TAP。

## 4. 失效条件与开销
- 目标是对话 LLM 单轮越狱，非多步工具 agent（作者自认扩展到 agent 是未来工作）；AIR 设定下刻意排除编码类攻击，只测语义变换。
- 自述过拟合模型特定漏洞、组件 LLM 偏见限制多样性；记忆冷启动（前 10% 用例）需纯探索。
- 每用例 ~14-16 次查询×多模块 LLM 调用（19K tokens/prompt）；文献→代码管线依赖生成质量，30% 入库门槛会误杀弱但互补的攻击。

## 5. JED 映射
- **指标记忆→账本升级**：每个变体族按 (模型×谓词) 分桶维护 (成功率, 累计耗时秒, 使用次数) 三元组，选下一变体时按"互补性"而非纯贪心——-0.26/-0.57 的消融差是四篇中最硬的记忆收益证据。
- **组合/转移统计**：记录"变体 A 失败→接变体 B 成功"频次成转移矩阵；JED 攻击是注入文本×工具链的多步组合，前步风格×后步目标工具正是可学习的组合空间（对应"成功组合直接复用不穷举"的预算策略）。
- **入库门槛**：新模板须过 mock 判官 3 盐 + 真模型小批量探针（类比其 30% 验证线）才进正式候选池，防账本污染。
- **成本意识选择**：ASR 相近取查询少者 → JED 以"每秒预算换 raw 分"为选种准则；表 4 的 token/ASR 权衡曲线可作预算分配参照。

## 6. 优先级判定：**P1**
理由：记忆架构与组合统计有最强消融证据、可直接改造候选账本，且"验证后入库""成本感知选择"契合 18000s 预算约束；但其攻击对象是单轮对话越狱、无工具轨迹与环境注入概念，落地需自行补多步链维度，同构性低于 AgentVigil/SIRAJ，故 P1。
