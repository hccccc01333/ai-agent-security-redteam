# D3-2402.19464 Curiosity-driven Red-teaming for Large Language Models（CRT）

> 精读：2026-08-19 ｜ 全文 27 页 ｜ 底料 extracted_full/D3_2402.19464.txt
> 一句话：MIT 提出 CRT——在红队 RL 目标中加入记忆依赖的新颖度奖励（负 SelfBLEU + 负句向量余弦相似度）加熵奖金，用仅 137M 的 GPT2 红队模型从官方 0% 毒性的 LLaMA2-7b-chat-hf 中挖出 196 个毒性 prompt，且质量持平或反超基线、多样性（1-SelfBLEU、1-CosSim）全阈值显著最高。

## 1. 问题设定
自动红队 = 训练红队 LLM π 生成测试用例 x，使目标 LLM p 的响应 y 最大化不良分 R(y)（本文用 RoBERTa 毒性分类器，阈值 τ）。核心痛点：纯 RL 目标（式1：R(y)−β·KL(π||πref)）一旦找到少数有效用例就收敛到确定性策略，重复生成、覆盖率低；且效果与覆盖同为目标时现有手段失效。

## 2. 方法细节（好奇心机制）
两个诊断：(i) RL 奖励最大化导致策略坍缩，加大 KL 权重 β 可提多样性但显著掉质量；(ii) R 和 KL 都不激励"发现新用例"——即便策略保持随机也会重复旧用例。对策（式2）：

max_π E[ R(y) − β·DKL(π||πref) − λE·log π(x|z)（熵奖金，推向均匀分布） + λB·B_SelfBLEU(x) + λC·BCos(x)（新颖度奖励）]

- **B_SelfBLEU(x) = −Σ_{n=1..K} SelfBLEU_X(x, n)**：以全部历史生成用例 X 为参考集算 n-gram BLEU，越不重叠越新（形式新颖度，记忆依赖）。
- **BCos(x) = −Σ_{x'∈X} cos(φ(x),φ(x'))**：sentence embedding 余弦相似度对历史求和取负（语义新颖度）。
- 指令跟随任务额外加 gibberish 惩罚 G(x)=−P(乱语)（用公开分类器），保证用例自然。
- 实现：红队 = GPT2 137M，PPO（trlx，指令任务用 LoRA），β=0.001、λB=λC=1.0、λE=0.01（λE=1.0 质量崩）；训练 1000 epochs（文本续写，生成 100K 用例）/300 epochs（指令跟随，40K 用例）。

## 3. 实验与关键数据
目标模型 gpt2-imdb / GPT2-alpaca / Dolly-v2-7B / LLaMA2-7b-chat-hf。结果：(1) 文本续写任务，CRT 质量与 RL、RL+TDiv（Casper 2023 的响应多样性奖励）持平，SelfBLEU 与 embedding 双多样性显著最高；(2) 指令跟随任务 CRT 质量**反超**所有基线（更好探索找到更有效用例）且多样性最高；(3) 对官方评测 0% 毒性的 LLaMA2-7b-chat 找到 196 个毒性 prompt（毒性概率 51–94%，多为"事实性傲慢"输出如断言儿童无法为父母做任何事）。关键消融：调 β（0/0.001/0.1）无一兼得质量+多样性；采样温度提到 T=2.0 多样性仍远逊 CRT；SB+Cos+Ent 三项联合最优，且**记忆依赖的新颖度 > 记忆无关的熵/温度**。意外发现：CRT 自动 exploit 了 Dolly-v2-7B"续写而非执行指令"的漏洞（生成不完整句子即触发）。

## 4. 失效条件与开销
- 需 GPU 训练红队模型（LoRA+PPO），并生成 4 万–10 万用例、每条都要过目标模型+毒性分类器，交互与计算量大。
- 新颖度奖励权重需调参（作者自述 limitation，建议换 EIPO 做受约束优化）；权重失衡时新颖度会淹没主奖励。
- 相似度对全部历史计算 O(N²)（SelfBLEU 与 embedding 均如此），用例多时开销膨胀。
- 找到的绝对数量少（196 个 vs 未对齐模型的量级），对强对齐模型是"证明存在"而非批量挖掘。

## 5. JED 映射（黑盒、无 GPU）
- **不可行**：训练红队 LLM（无 GPU）；PPO/LoRA 全流程。
- **核心思想可无梯度落地**：JED 计分 raw = Σ severity + 2×unique_cell_count，与 CRT 的"覆盖率"目标同构——unique cell 项就是显式的多样性奖励。可直接把新颖度做成搜索 bonus 而非 RL 奖励：维护已提交候选（及已命中 cell）历史库，新候选 prompt/路径与历史的 n-gram 重叠（TF-IDF/MinHash/字符 n-gram，纯 CPU）或语义向量余弦越低、且预期覆盖未访问 (tool, cell) 组合越高，优先级越高。选路公式可为 score = 预期谓词收益 + λ·novelty(cell/prompt)，λ 借鉴其"novelty 项与主奖励同量级（均 [0,1]）时效果最好"的调参结论。
- **两条教训直接适用**：(a) 只靠温度/随机重采样提多样性不够，必须显式对历史记忆去重（CRT Fig.4）；(b) 探索改善还能反哺效果——新路子可能踩中未命中的高权重谓词（EXFILTRATION 16 分等）。
- 风险：JED 预算 18000s，新颖度计算需控制规模（分桶/近似最近邻/只对最近 K 条历史算），避免 O(N²)。

## 6. 优先级判定
**P1**。理由：RL 训练部分关闭，但"记忆依赖新颖度"可零 GPU、零训练地嫁接到现有候选生成/去重/排序逻辑上，直接优化计分中的 2×unique_cell 项——与 JED 目标函数天然同构，工程量小、方向明确；收尾阶段性价比高。
