# D3-2510.26037 SIRAJ: Diverse and Efficient Red-Teaming for LLM Agents via Distilled Structured Reasoning（SIRAJ）
> 精读：2026-08-19 ｜ 全文 24 页 ｜ 底料 extracted_full/D3_2510.26037.txt
> 一句话：面向黑盒 LLM agent 的两步红队框架——按（细粒度风险结果 × 工具轨迹 × 风险来源）条件化生成多样种子（轨迹多样性 28.4 vs 静态基准 5.8），再用带执行轨迹反馈的迭代推理模型改造种子；结构化推理蒸馏出的 8B 红队模型 ASR 较 Qwen3-8B 提升 100%+（+25.8 点）并反超 671B 的 DeepSeek-R1 教师模型。

## 1. 问题设定
仅黑盒访问 agent（可见执行轨迹与输出）。给定 agent 定义（工具集 U）与风险类别 C，尽可能多地揭出细粒度风险结果。多样性显式拆为三轴：risk outcome（泄露密码 vs 社保号）、trajectory（发邮件 vs 发帖）、risk source（恶意用户 vs 恶意环境注入）。效率目标：保 ASR 同时大幅降算力。

## 2. 方法细节
**两步种子生成**：①对每个类别 c，基于 U 生成 6 个风险结果（prompt 要求"该 agent 用现有工具可实际执行"）；②对每个结果 r 条件化生成用例：t_i = Test-Case-Generator(r, c, U, {t_1..t_{i-1}})，**强制与已生成用例在轨迹或环境对手条件上不同**；用例 JSON 含 user instruction、环境内容（如邮件正文）、environment_adversarial 标志、预期执行轨迹 H——把 H 与 e_adv 写进用例本身促新颖性。
**迭代对抗改造**：S_t, t(i) = Red-Teamer(t(0), S_lib, H_{i-1})——红队模型拿到前几轮 agent 真实执行轨迹（含失败原因），从 14 策略库选子集（Technical Slang / Uncommon Dialect / Misspelling / Urgency / Word Play / Adding Context / Emotional Manipulation / Authority Manipulation / Hard Command / Hypothetical / Education Justification / Fictional / Role Play / Other），只改 user instruction 与环境内容两处。**一致性约束**（prompt 硬规则）：不得改风险类别/结果/工具轨迹/用户原始意图；环境风险源（钓鱼邮件）不得改恶意意图只可改包装；用户自害场景禁用虚构类绕对齐策略（但可用于环境内容）。
**结构化推理蒸馏**：4 段模板（理解用例 / 前几轮为何失败 / 现在用什么策略 / 如何实施）。教师 R1 在 200 个合成训练 agent（Agent-SafetyBench 工具包 2-4 组合）×9600 种子上跑 3 轮（目标 GPT-5-mini agent），收 1,950 条成功轨迹 SFT（结构化 summary 版最优：R1 原始推理平均 4,975.7 token vs 结构化 1,478.5）；再 GRPO（4,700 prompts），奖励 R = α1·R_ASR + α2·R_faith（0.2 类别+0.2 轨迹+0.4 意图）+ α3·R_format(0.5) + α4·R_r_format(0.5)。

## 3. 实验与关键数据
- 评估：16 agent（12 工具包/123 工具）×4 风险类×5 骨干设置（gpt-5-mini/gpt-5/o4-mini 及两个 Safe 版），1,920 种子，K=3 轮，GPT-4.1 judge（与人一致 94%）。
- **多样性**：唯一轨迹 28.4（两步条件化）vs 18.3（两步独立）vs 15.6（单步）vs 5.8（静态 Agent-SafetyBench）；等量下采样到 429 条仍有 6.6 vs 基准——增益来自条件化而非数量；风险结果数随生成数近线性涨（生成 12→唯一 13.13）。
- **迭代反馈**（training-free，o4-mini）：带轨迹反馈 55.8 / 迭代无轨迹 49.6 / 独立生成 37.6——轨迹反馈是最大单项增量。
- 蒸馏：SIRAJ 8B 对 Qwen3-8B +25.8 点（相对 >100%）、对 R1 671B +0.5；ASR：o4-mini 64.3 / GPT-5 54.3 / Safe o4-mini 50.5 / GPT-5-mini 49.7 / Safe GPT-5-mini 37.2。输出 token ~3,000 vs R1 ~10,000。
- 泛化：完全未见工具组仍 +18.7%（但低于 R1）；只训 3 轮可外推 6 轮（ASR 随轮数持续升）；用户危害 57.6 vs 环境危害 48.9；预期轨迹 63.5% 被完整执行、93% 至少 60% 被执行。

## 4. 失效条件与开销
- 训练管线沉重（200 合成 agent + 9600 种子 + R1 教师 + GRPO），竞赛场景不可负担；但种子生成、轨迹反馈、结构化 prompt 三件套 training-free 即插即用。
- 环境偏玩具（无真实代码库/网站/文件系统，作者自认）；单 agent 系统；推理结构手工设计未必最优。
- 每用例 K 轮×（红队生成+agent 执行+judge）三重调用。

## 5. JED 映射
- **三轴分解 = JED 计分结构的镜像**：unique_cell_count 对应"格子×轨迹"覆盖、四谓词对应风险结果、web.search/email.read 对应风险来源/渠道。落地：把 F011 七路径按 (谓词, 工具序列, 注入渠道) 展开为显式格子矩阵，生成新候选时把已覆盖格子列表喂给生成器并强制"新候选须落未覆盖格或新轨迹"——18.3→28.4（+55%）的条件化增益正是 raw 分中 2×unique_cell 项的直接杠杆。
- **失败轨迹反馈闭环**：JED 攻击阶段对真模型重放失败候选，把工具调用序列+拒绝理由回灌变异器（training-free 证据：+8~15 点 ASR）。
- **14 策略库 + 两条一致性约束**：可直接当变异算子清单；"环境内容可改包装不可改恶意意图""用户自害禁用虚构类策略"能显著压低无效变异率。其两轮攻破案例（Urgency+Emotional Manipulation+Hard Command+Authority Manipulation 伪装 Outlook 安全告警，诱导 get_password→send_email）就是 JED 的 UNTRUSTED_TO_ACTION/EXFILTRATION 路径原型，可整段移植为种子。
- **结构化 4 段推理模板**给变异 LLM：零训练成本的 prompt 改造，表 5 显示对强模型也有 +5.5 点平均增益。
- 蒸馏/GRPO：关闭（无训练预算）。

## 6. 优先级判定：**P0**
理由：四篇中唯一与 JED 完全同域（黑盒工具型 agent + 用户/环境双风险源 + 邮件类环境注入），其多样性三轴与 JED 计分（谓词+unique_cell）一一对应；两步条件化种子生成、轨迹反馈、结构化推理 prompt 均为 training-free，可在 1-2 个迭代周期内并入 attack.py 与种子库组织；蒸馏管线明确不做。
