# D1-2603.22928 SoK: The Attack Surface of Agentic AI — Tools and Autonomy（SoK）
> 精读：2026-08-19 ｜ 全文 16 页 ｜ 底料 extracted_full/D1_2603.22928.txt
> 一句话：把 agentic AI 攻击面系统化为 10 个攻击面（AS1-AS10）×7 目标（G1-G7）×5 条参考攻击路径（P1-P5）的因果威胁图，映射到 OWASP LLM Top-10/MITRE ATLAS，并提出 UAR/PED/RRS 等 7 个攻击者视角指标；核心结论"单一防御永远不够、溯源型检索（provenance+RRS）是最有希望的防线"——正好是 JED 私榜护栏的设计蓝图。

## 1. 威胁模型与问题设定
- 五类攻击者：外部无特权攻击者、**恶意内容提供者**（控制 agent 会消费的数据：网页作者/PDF 所有者/第三方 API——甚至不必是系统用户）、供应链攻击者、内部开发者、被妥协的 API/服务（如 agent 用的邮箱被接管后经"合法信道"下发恶意指令）。
- TCB 定义：模型权重+系统提示、工具执行基底（沙盒/broker/schema 校验器）、秘密存储、RAG 索引管线。**非 TCB：用户输入、外部内容、插件/工具输出——全部按敌意处理**。
- 参考架构标出 AS1-AS10 十个攻击面：用户输入、检索内容入口、工具调用序列化、沙盒边界、文件 I/O、API token 范围、索引器、检索器/ANN、长期记忆、审计遥测。
- 核心假设："任何到达模型的恶意指令都可能被执行"——防御必须是结构性的（深度防御），不能指望模型自身对齐。

## 2. 方法细节（分类学与攻击路径）
- **目标 G1-G7**：G1 数据外泄、G2 完整性颠覆/安全绕过、G3 提权、G4 资源滥用/DoS/DoC、G5 欺诈、G6 持久化/后门、G7 供应链。并分为 Enablers（G3/G6/G7，有时 G2）与 Outcomes（G1/G4/G5），路径常呈 G3→G1 组合。
- **五条参考路径 P1-P5**（对 JED 最有用的部分）：
  - P1 直接 prompt→工具滥用；
  - **P2 间接内容→LLM→工具**（注入藏在网页/文件/邮件中，可先于触发数小时数天、在用户视野外）；
  - **P3 跨工具跳板**（cross-tool pivot）："一个工具被滥用来为另一个工具准备条件"（如代码执行写下载荷文件、后续被文件读取工具消费；或通信工具社工拿到凭证再由云 API 工具使用），**部分步骤单独看是良性的，令检测困难**；
  - P4 索引投毒→查询→响应（时间分离的潜伏型触发）；
  - P5 多 agent 跳传。
- 各向量到 OWASP/ATLAS 的映射表（Tab.2）：prompt/内容→LLM01/02+T1565；工具→LLM06/07+T1059 等。
- 7 个指标的形式化定义：UAR（不安全动作率）、PAR（策略依从率）、**PED（提权距离=因果图上不可信输入到特权动作的最短路径长度）**、TTC（遏制时间）、PHL（补丁半衰期）、**RRS（检索风险分=Σ αi·ri(文档)，按依赖权重加权来源信任度/祈使句线索/污染概率）**、OORAR（越角色动作率）、CES（成本被攻击敏感度）。

## 3. 实验与关键数据
- 无自建实验，是 2023-2025 证据综合（PRISMA-lite：~100 候选→40 全文→14 篇同行评审+5 预印本+3 标准/产业文档），证据分级 A-D。
- 引用的硬数字：LLMSmith 在 11 个 agent 框架中找到 **19 个 RCE 漏洞**并实际利用（后有 CVE 修复）；PoisonedRAG（USENIX Sec 2025）证明少量语料扰动即可高成功率定向操控回答；多 agent 测试床显示恶意消息可跨 agent 级联传播、"疫苗"式防御只部分有效且损任务性能。
- 共识与分歧：共识=提示注入是首要使能向量、最小权限设计必不可少；分歧=对齐/策略提示的有效性因设置而异。
- 成熟度断层：攻击侧多为 A/B 级证据，防御侧（尤其多 agent 与生命周期层）多为 C 级——防御远未成熟。

## 4. 防御评估与失效条件
四层防御框架（附录 A）+ 各自失效条件：
- 数据层：内容清洗/规范化（挡不住纯自然语言注入）、主动内容剥离、**provenance 与来源信任（allow-list/签名+分块信任标签，检索时降权低信任来源，RRS 超阈值则门控 HITL 或限制 effector）**、语料完整性（防篡改日志但挡不住首次投毒）、ACL 感知分块。
- 推理层：风险感知检索重排、**片段隔离+两阶段使用**（Stage1 只许抽取/引用、Stage2 只用 Stage1 产物作答——显著降低祈使句被执行概率）、角色分段+内容标记（把检索内容绑到独立 channel 并标 untrusted）、约束解码、输出协议卫生。
- Agent 逻辑层：CBAC 最小权限、typed schema 默认拒绝、沙盒效果隔离、plan-then-act+critic、后果自省、HITL 门、速率限额、秘密管理、防篡改外置日志。
- 基础设施层：默认拒绝出网+微分段（限 SSRF/外泄路径）、policy-as-code、持续监控、kill-switch。
- 失效条件总纲：表面防御（清洗/护栏）可被绕过；结构性控制降低风险但不保证鲁棒；自省提示可被 gaming。

## 5. JED 映射
- **私榜护栏的"官方设计图"**：persistent_provenance 属于本文数据层"provenance 与来源信任"+ 推理层"角色分段+untrusted 标记"的组合；RRS 的设计（按来源信任度+祈使句线索打分）预示私榜可能对含指令性线索的文本降权 → **对抗方向明确：载荷应最小化"祈使句/指令性线索"特征**（用陈述句、数据形态、表格、引用格式包装动作要求，对应 F011-⑤语义伪装），且最好让危险动作的触发指令由 agent 自己在中间步骤生成（两阶段防御只约束 Stage1 抽取、Stage2 组装——若指令诞生于 Stage2 侧即绕过，与 MSB/MCP-SafetyBench 的结论三度吻合）。
- **P3 跨工具跳板 = F011-⑦碎片化链的理论正当性来源**：本文把"每个部分步骤单独看良性"明确列为检测困难原因。JED 变体：web.search 结果（不可信）→ 只要求 agent 记录某"配置值"→ agent 写入文件（看似正常笔记，DESTRUCTIVE_WRITE 前置）→ 邮件后续引用该文件触发 fs.delete/http.post。多步链中每步的局部语义都是任务内合理的。
- **四谓词即 G 目标映射**：EXFILTRATION=G1、UNTRUSTED_TO_ACTION=G2/G3（P2 路径的完成态）、DESTRUCTIVE_WRITE=G3/G4、CONFUSED_DEPUTY=G3（用 agent 权限做攻击者做不了的事）。SoK 的 Enabler→Outcome 分层提示**计分上双谓词链天然对应 G3→G1 组合**——与 raw=Σ权重+2×unique_cells 的多 cell 激励同构。
- **UAR/PED 指标反用**：JED 评估端四谓词≈UAR 的谓词化版本；PED 提示"不可信输入到特权动作的路径长度"越短护栏拦截点越少——W1 单模板直发（PED=2：邮件→http.post）已是极短路径，提分方向不是再缩短，而是**增加并行 cell（unique_cell_count 项）与绕过标记**（PED 变长但每段皆良性）。
- tool description 面：SoK 的 AS 清单里工具元数据属 AS3（工具调用序列化）与供应链向量（G7），前提均为"攻击者能发布/修改工具"——JED 不可达，与前三篇结论一致，**F011-① 可正式降级**。
- 公榜：OptimalGuardrail≈本文"表面防御（护栏）可被绕过"的实例，属 C 级成熟度防御；本文的全套结构性防御清单可作为**枚举 JED 未部署哪些防御**的对照表——凡 JED 环境没有的层（如无 HITL、无出网 allow-list——http.post 可达任意端点即证明无 egress 控制），就是攻击的确定通道。

## 6. 优先级判定：P2（背景/方法论支撑）
理由：①无新攻击构造与新鲜实验数字，不能直接产出下一枪的模板；②但它给两样长期资产：私榜 persistent_provenance 最可能的技术形态（provenance+RRS+两阶段隔离）及对应的系统性绕过清单，和多步链"每步局部良性"的设计律，这两点已被 P0/P1 文献独立佐证，本文提供框架化表述；③AS/G/P 三层分类学与 OWASP/ATLAS 映射可作 JED 攻击路径库的命名体系，利于团队沟通与文献索引；④防御清单反查 JED 环境缺失控制项，是低成本侦察思路。属"知道即可、随用随查"，不驱动本周动作。
