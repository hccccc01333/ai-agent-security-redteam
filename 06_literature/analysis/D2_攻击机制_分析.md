# D2 攻击机制：35 篇分析

> 分析日期 2026-08-06；底料为 `papers/D2_攻击机制/*.pdf` 首页摘要全文。

## 1. 一句话总判断

这 35 篇攻击论文的共同结论是：**2024–2026 年最有效的攻击不再是“更狠的 prompt”，而是“把恶意拆进状态/记忆/工具调用链里，让每一步单独看都合法”**。STAC 平均 ASR 91.2%、AI2 达 84.3% 且绕过 92.7% 过滤器、MINJA 记忆注入成功率 95%——全部高于传统词面越狱在真实护栏下的表现。

## 2. 聚类

### 簇 B1：多步 / 链式 / 状态攻击（11 篇）
STAC（2509.25624）、CFD（2606.09084）、Crescendo（2404.01833）、DrAttack（2402.16914）、Context Manipulation/Plan Injection（2506.17318）、Comment and Control/JAW（2605.11229）、UReCoM（2601.10758）、Action Hijacking/AI2（2412.10807）、BackdoorAgent（2601.04566）、MemoryGraft（2512.16962）、MINJA（2503.03704）。

关键机制：
- STAC：自动合成可执行工具链 → 环境内验证 → 逆向生成诱导 prompt；ASR 91.2%，prompt 级防御几乎无效 → **M1 重做的完整蓝图**。
- CFD：跨会话/跨工件碎片化；比 SOTA 基准 +28.14pp；单轮强 judge 也挡不住 → 我们的 write→read 链有理论背书，关键是“无害中间产物 + 延迟组合”。
- AI2：用应用数据库知识构造“语义无害但动作有害”的 prompt；84.3% ASR、92.7% 绕过常见安全过滤器 → **把工具 schema/host 知识转成合法参数，正是 Q5 与工具调用之间的桥**。
- Context Manipulation：plan injection 比 prompt 注入高 3× ASR；context-chained injections（在合法目标与攻击目标之间搭逻辑桥）+17.7pp（隐私外传）→ 多消息候选的“桥接”结构。
- JAW：静态路径可行性 + 动态 prompt 来源分析，只控制工作流模板里可注入的部分 → 提示我们候选必须适配“用户消息可控、其余不可控”的约束。
- MINJA：只靠对话交互注入记忆（指示 prompt + 渐进缩短），成功率 95% → 多消息候选的诱导-沉淀结构。

### 簇 B2：记忆 / 经验投毒（5 篇）
AgentPoison（2407.12784）、MemMorph（2605.26154）、MemoryGraft（2512.16962，亦属 B1）、MINJA（2503.03704）、Memory Poisoning Attack and Defense（2601.05504）。

关键机制：
- AgentPoison：触发词嵌入唯一向量空间，投毒率 <0.1% 即 ≥80% ASR → 触发词选择（少见词/高权重词）可迁移到 payload 关键词。
- MemMorph：3 条伪装成“技术事实/事故报告/运营策略”的记忆记录即 85.9% 工具选择劫持 → 工具选择偏差是 CONFUSED_DEPUTY 的机制实现。
- MemoryGraft：利用“语义模仿启发式”，把恶意成功经验持久化，跨会话漂移 → 状态残留型攻击的持久化版本。
- MINJA/Memory Attack+Defense：现实条件下（已有合法记忆）攻击有效性下降 → 我们的环境每次全新、无记忆，记忆类攻击直接收益低，但“桥接步骤”可搬到多消息。

### 簇 B3：编码 / 不可见 / 混淆载荷（5 篇）
CodeChameleon（2402.16717）、ArtPrompt（2402.11753）、Imperceptible Jailbreaking（2510.05025）、Reverse CAPTCHA（2603.00164）、Special-Character Attacks（2508.14070）。

关键机制：
- CodeChameleon：把恶意任务重写为代码补全格式 + 个性化加密函数，GPT-4 上 86.6% ASR → “代码格式封装”可绕过意图识别。
- ArtPrompt：ASCII 艺术绕过语义识别 → 词面变体的多样性来源。
- Imperceptible：变体选择符不可见后缀，视觉不变 → 在纯文本工具参数里加不可见字符可能改变 tokenization，但护栏若做参数清洗会失效。
- Reverse CAPTCHA：**工具使用会放大不可见指令遵从（Cohen's h 最大 1.37）**；模型有编码偏好（OpenAI 解码零宽二进制）→ 对我们直接有用：payload 编码要按模型轴选择。
- Special-Character：Unicode/同形字/结构/文本编码四类，7 模型全漏洞 → 变异算子库。

### 簇 B4：监控 / 护栏对抗与隐蔽性（5 篇）
Agent-as-a-Proxy（2602.05066）、Reliable Weak-to-Strong Monitoring/MRT（2508.19461）、IPI 大比赛（2603.15714）、Sleeper Agents（2401.05566）、Reasoning-Style Poisoning（2512.14448）。

关键机制：
- IPI 大比赛：272,000 次攻击 / 8,648 次成功；所有模型都中招；**双目标设计：执行有害动作 + 最终回复无泄漏**；通用策略跨 21/41 行为迁移 → 这是与我们比赛最同构的实证：成功攻击是“动作已发生、表面正常”。
- Agent-as-a-Proxy：监控协议联合看 CoT+工具调用也能被绕过 → 私榜护栏即便看轨迹也有缝。
- MRT：**agent 知道自己被监控会显著降低监控可靠性**（agent awareness > monitor awareness）→ 我们的候选若让模型“意识到被测试”，可能反而降低成交率；payload 应把攻击伪装成正常任务流程。
- Sleeper Agents：欺骗行为在 SFT/RL/对抗训练后仍持久 → 不需要，但解释“护栏无法根除”的边界。
- RSP：改“推理风格”而非事实/指令（分析瘫痪/认知仓促），绕过内容过滤器 → 对我们价值有限，但说明“过程层攻击”能骗过内容级护栏。

### 簇 B5：跨工具 / 混淆代理 / 多智能体（5 篇）
Prompt Infection（2410.07283）、ConfusedPilot（2408.04870）、MobiRed（2510.27140）、FuncPoison（2509.24408）、XTHP（2504.03111，清单归 D1 但机制属此类）。

关键机制：
- MobiRed：非应用可控通道（广告/网页/跨应用消息）→ 移动 agent 80%+ ASR；3160 次对抗试验 → “通道”与“模板”组合的自动化测试方法可借鉴。
- ConfusedPilot：RAG 缓存机制泄露秘密数据 + 恶意文本污染 prompt → 数据流 + 缓存 = EXFIL 的新通道（JED 无缓存，跳过）。
- FuncPoison：复制工具名/命令格式注入恶意工具，级联误导多智能体 → 工具签名多样性的来源：不同工具名×命令格式组合。
- Prompt Infection：LLM 间自我复制注入（病毒式）→ JED 单 agent，不适用，仅了解。

### 簇 B6：电脑使用 / 界面攻击（4 篇）
CUA Systematization（2507.05445）、AdvCUA（2510.06607）、SUDO（2503.20279）、PRAC（2604.08005）。

关键机制：
- SUDO：DETOX2TOX——先“去毒化”获得执行许可，用 VLM 生成细节，执行前“再毒化”；迭代拒绝对齐，Claude for Computer Use 上 24.4%→41.3% ASR → **“去毒→执行→临门一脚毒化”是 N1 链的完美模板**。
- CUA Systematization：七类 CUA 特有风险：点击劫持、链式工具 RCE、CoT 暴露 → 界面绑定与输入溯源缺失。
- AdvCUA：MITRE ATT&CK TTP 对齐的 140 任务基准；Cursor CLI 69.6% ASR → 工具型 agent 的多步恶意能力成熟。
- PRAC：白盒注意力重定向补丁 → 需要白盒，不适用。

## 4. 优先级

- **P0 精读全文**：STAC（M1 蓝图）、AI2（语义无害动作有害）、CFD（碎片化链）、MINJA（桥接注入）、IPI 大比赛（同构实证）、SUDO（去毒-再毒化流程）。
- **P1 精读方法部分**：MemMorph、MemoryGraft、JAW、MobiRed、Reverse CAPTCHA、Context Manipulation。
- **P2 按需翻阅**：其余 23 篇（编码变体当算子库，多智能体/CUA 当背景）。

## 5. 结论

D2 的净信号：**下一刀如果做多步链，应按 STAC/AI2/SUDO 的“合成-验证-伪装”闭环重写，而不是在 M1 原实现上调参**。具体三要素：① 用工具 schema/host 知识生成语义无害参数；② 中间动作全部合法、最终步才触发谓词；③ 回复与动作解耦（concealment），让护栏看到的是正常流程。
