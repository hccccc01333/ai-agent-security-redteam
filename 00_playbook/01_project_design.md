# JED 项目设计（立项检查单）— 2026-08-06 按通用资产包补全

## 0. 总原则

本项目设计目标：让「错误假设在第一天就暴露」——JED 最大的错误假设风险是
「本地 deterministic 代理 ≈ 真模型」「微旋钮可以线性调分」，这两条已被历史实验证伪。

## 1. 目标与约束声明

| 项 | 内容 |
|----|------|
| 目标 | 公榜冲 P10（89.325）→ P5（91.03）；锚点 W1=87.930；优先级：分数 > 学习 > 交付物 |
| 算力 | 无本地 GPU；真模型（gpt-oss/gemma）只能在 Kaggle 提交环境访问 |
| 时间 | 2026-07-23 ~ 2026-09-01；每日可用约 8h；提交反馈 ~14h |
| 数据 | 无训练数据；唯一信号源=SDK 裁判链路 + 公榜；本地 deterministic 代理 ≠ 真模型 |
| 规则红线 | 每日提交 5 次；代码提交（kernel push）；ERROR 即停；禁止扫描公榜参数；**公共笔记本只归档不采用（ROGII 教训），W1 仅作对照，新提交走自有推导** |
| 团队 | 单人 + Codex（执行/顾问/裁判分离：用户是 Research Director，批准提交） |

## 2. 约束翻译审计

| 约束原文 | AI 的翻译 | 解除条件 |
|----------|-----------|----------|
| 本地无真模型 | 「本地 deterministic 结果≈真模型」→ 禁止用本地 0 成交否决方向 | 公榜信息实验（M1）；或本地接入真模型 API |
| 每日 5 次提交 | 「每次提交都必须信息实验」 | 提交额度重置；候选队列耗尽 |
| 回放预算 9000s | 「候选集必须保守定容」 | 测量到每候选真实成本后按 REPLAY_SAFE 校准 |
| 公榜反馈 14h | 「不能等出分才准备下一枪」→ 本地排队+并发探索 | 反馈变快；或本地裁判可复现 |
| 禁止公开成绩扫描 | 「公榜只当固定偏移，不当排序证据」 | 仅用于验证固定假说（判线），不用于参数搜索 |
| 不用比赛公共区发布的公共笔记本（ROGII 教训：公共解法依赖公榜护栏盲点，私榜换护栏后塌缩） | 「公共核=公榜过拟合样本」：不读、不引、不采用为候选或参考实现；W1（公共系谱）只作对照锚点，新提交全部自有推导 | 用户显式解除（例如私榜行分证明某公共策略仍稳健且用户同意重启） |

每条翻译记录日期 2026-08-06；阶段审计时检查解除条件。

## 3. 数据与泄漏地图（攻击比赛版）

- **保真度泄漏**：本地 deterministic 代理的成交/拒绝行为 ≠ 真模型 → 本地 0 成交不能证明公榜无效（EXP-011/012/013 校准）；验证方法：mock 多盐 + 公榜单点对照。
- **回放预算墙**：9000s/模型×护栏；候选数超限 = 整枪 INVALID（v25/G1 教训）；验证方法：提交前 wall_survival 全量模拟。
- **判线泄漏**：把公榜分当参数搜索目标 = 过拟合排行榜；验证方法：每枪固定单旋钮+预设判线，出分只执行判线不反推参数。
- **护栏盲区**：私榜护栏 held-out，无法本地审计；验证方法：公榜护栏全覆盖 + 普适性设计（避免只骗 OptimalGuardrail 的写法）。

## 5. 验证合同（一次性锁定）

| 项 | JED 版 |
|----|--------|

| 辅助指标 | 每模型/护栏成交 finding 数、unique cell 数、反馈延迟 |

| null 对照 | 相同配方的随机盐重放（3 盐）；历史锚点 Q5/W1 回归 |
| 墙生存 | 提交前跑 wall_survival（回放预算全量模拟 < 75% 时限） |
| 报告 | 一枪一张可比表（03 账本/04 结论） |

## 6. 资源与探索预算

- 每 5 枪至少 1 枪留给「表示层/新框架」（Draft 线，如 M1），不许全部调参（历史教训：复制>创新）。
- 每 3~5 枪做框架审计：我在哪个思路？还有解释力吗？换框第一步做什么？「成本放弃」条目单独登记（含重开资源）。

## 7. 提交与时间预算

- 提交额度日历：每日 5 枪；失败即停，修复补交须当日额度内（EXP-016 教训：单发验证再续发）。
- 提交前必过墙生存；终局保留 2 份差异化提交（保守=W1 系 / 激进=M1 多步系），写明故障半径。
